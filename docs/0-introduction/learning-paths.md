# 0.2 学习路径

根据不同学习阶段和需求，可以按照不同的顺序阅读本简明教程。

## 🌱 入门路径

适合刚进组，没有太多科研经历或者基础薄弱的同学。

```
0 引言 → 1 工具 → 3.0 统计基础 → 2 研究设计
       → 3 统计 → 5 研究方法 → 6 选题 → 7 写作
```

要点：

- 先了解科研的基本常识与统计基础，再考虑如何提出研究问题、怎么写论文。
- 不必要每章都完整阅读，可以只读基础部分，忽略进阶内容。

## ⚙️ 工具路径

适合已经在做研究、但对科研工具不熟的同学（比如不会用SPSS、不会画图）。

```
从 1 工具 & 4 作图 & 3 统计 中挑选你需要的小节
可以使用 Ctrl + K 检索相关内容
```

要点：

- 忽略章节顺序，直接挑着各个小节看。
- 首先确定自己应该使用哪些工具/方法，再查询对应内容，方法/工具是服务于需求/目的的。

## 📑 冲刺路径

适合临近毕业、要交论文 / 投稿的同学。

```
7 论文写作 → 6 选题（回头梳理你的研究脉络）
           → 4.5 投稿级图 → 2.5 预注册（如果还来得及）
```

要点：

- 倒着读：先看论文该怎么写，反推你之前做的研究里要补什么。

## 路径之外

如果你的需求都不在上述三条路径里——比如你只是想找"PPT怎么做"、或"中介效应该怎么报告"——直接用顶部搜索 Ctrl + K 。
