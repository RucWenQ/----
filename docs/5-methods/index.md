## 本章导读

本章帮助你在已经有研究问题之后，选择能真正回答它的资料和设计。先从 [2 · 研究设计](../2-design/) 固定估计目标、变量和伦理边界，再按问题选择情境问卷、实验、量表、纵向、二元或质性方法；最后回到 [3 · 统计](../3-statistics/) 和 [4 · 科研作图](../4-visualization/) 完成分析与呈现。

<OutlineCard title="本章七节">

- [**5.1 情境问卷 / vignette**](./vignette)：把情境操纵、理解检查和问卷结果连接起来。
- [**5.2 实验室实验**](./lab-experiment)：控制环境、随机化和操作检查。
- [**5.3 现场实验**](./field-experiment)：在真实场域中处理干扰、依从和实施记录。
- [**5.4 量表研究**](./scale-research)：从选择或改编量表到结构、信度、效度和可比性。
- [**5.5 纵向 / 日记 / ESM**](./longitudinal)：把变化、时间间隔、依从和被试内效应分开。
- [**5.6 二元数据 / APIM**](./dyadic)：处理伴侣、朋友、亲子等配对相依资料。
- [**5.7 质性方法概述**](./qualitative)：从访谈或观察到编码、主题和可追溯报告。

</OutlineCard>

## 如何选入口

| 你最想回答的问题 | 先读哪里 | 需要提前写清什么 |
| --- | --- | --- |
| 操纵某个情境是否改变态度？ | [实验室实验](./lab-experiment) 或 [现场实验](./field-experiment) | 随机化单位、干扰、主要结果和操作检查 |
| 某构念如何被稳定测量、比较或改编？ | [量表研究](./scale-research) | 构念边界、计分、目标人群和效度证据 |
| 同一个人如何变化，或今天的状态是否预测明天？ | [纵向 / 日记 / ESM](./longitudinal) | 时间尺度、提示规则、缺失和被试内/间效应 |
| 两个人的回答如何相互关联？ | [二元数据 / APIM](./dyadic) | 二元组、角色、隐私和相依结构 |
| 参与者如何理解经历、互动或制度？ | [质性方法](./qualitative) | 资料来源、研究者立场、编码取向和停止规则 |

## 本章的共同检查点

无论选择哪一节，先完成一页研究方法备忘录：

1. 研究问题、目标人群、观测单位和主要估计目标；
2. 资料如何产生、谁可能缺席、缺失和退出如何记录；
3. 设计中哪些假设支持你的解释，哪些推论明确不做；
4. 数据字典、版本、伦理审批、匿名化和可复现交付的位置；
5. 预先规定的主要结果、诊断、敏感性分析和报告模板。

方法页给的是最小可执行路径，不替代伦理审查、领域专家或正式统计咨询。遇到高风险参与者、复杂依赖结构、跨文化测量或无法解释的模型诊断时，保留原始记录并尽早求助。
