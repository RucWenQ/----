# 5.5 纵向 / 日记 / ESM

::: tip 本节目标
读完本节后，你能把变化问题转成合适的时间设计，区分波次、日记与经验采样，规划提示和依从记录，分开被试内与被试间效应，并按真实时间结构分析缺失、滞后与不确定性。
:::

## 5.5.1 先说清要研究哪一种变化

**纵向研究**对同一观测单位在多个时间点重复测量。它能描述变化、建立时间先后并研究个体差异，但“先发生”只是因果解释的必要条件之一；未测混杂、选择性流失、测量反应和错误时间尺度仍可能产生非因果关联。

先把问题写成可估计的形式：

| 问题 | 例子 | 需要的设计信息 |
| --- | --- | --- |
| 平均轨迹 | 新生归属感在一学年如何变化？ | 至少多个有理论意义的波次；时间起点与间隔 |
| 轨迹差异 | 哪些人的变化更快？ | 足够的参与者和波次；时间不变预测变量 |
| 被试内共变 | 一个人比自己平常更孤独时，是否也更少互动？ | 同一人的多次测量；状态变量与测量时点对齐 |
| 滞后预测 | 今日压力是否预测明日睡眠？ | 预先指定滞后、时间戳和足够连续的观测 |
| 事件过程 | 冲突发生前后情绪如何变化？ | 事件定义、触发窗口和无事件时段的比较 |

观测单位通常是一名参与者在一个时点的一次记录，记录嵌套于参与者；还可能嵌套于家庭、团队或测量批次。变量要标明层级：性别等稳定属性在被试间变化，今日压力同时包含被试内波动和人与人之间的平均差异。

## 5.5.2 选择波次、日记或 ESM

| 设计 | 典型采样 | 适合的问题 | 主要风险 |
| --- | --- | --- | --- |
| 面板/队列 | 间隔较长的若干波次 | 发展、转变、长期相互预测 | 波次过少、间隔与过程不匹配、流失 |
| 每日日记 | 每日固定时段一次或数次 | 当日经历、总结性状态和短期累积 | 回忆偏差、周内规律、漏填后补 |
| 经验采样/EMA | 随机、半随机或固定提示 | 当下状态、情境与快速被试内过程 | 负担、打扰、提示反应和时间自相关 |
| 事件触发记录 | 指定事件发生后填写 | 稀有或有明确起点的事件过程 | 漏报事件、事件定义不一致 |
| 测量突发 | 多段密集测量，中间间隔较长 | 长期变化中的短期动态 | 突发段之间可比性和复杂层级 |

“测得更频繁”不自动更好。测量间隔应覆盖理论过程：若反应在数分钟内消退，每周测量无法识别它；若变化以月为单位，过密提示可能只增加负担。预试参与者完成时间、提示干扰和回答类别分布，再确定频率与持续天数，不使用脱离情境的固定次数规则。

## 5.5.3 把时间和采样计划写进方案

时间不是简单的第 1、2、3 次。记录计划发送时间、实际打开时间、提交时间、时区和事件时间；明确可接受响应窗口及跨日规则。若间隔不等，模型中的时间变量应使用真实经过时间，并说明单位是小时、天还是月。

经验采样常见方案包括：

- **信号触发**：在预定窗口随机提示，适合估计日常状态分布；
- **固定间隔**：在固定时刻提示，执行简单，但可能与日程系统性重合；
- **事件触发**：由参与者在事件后启动，贴近过程但依赖事件识别和报告；
- **混合方案**：同时记录随机时点与关键事件，需要区分两类记录的纳入概率。

启动前固定静默时段、重发规则、过期规则、奖励、退出方式和异常事件处理。保存实际提示日志，而不只保存成功提交的数据，否则无法区分“没有提示”“提示未送达”和“参与者未回应”。涉及定位、通讯录或被动传感时，数据最小化、权限与风险响应见 [2.6 研究伦理](../2-design/ethics)。

## 5.5.4 分开被试内与被试间效应

若 $X_{it}$ 是参与者 $i$ 在时点 $t$ 的状态，把它拆成个人均值 $\bar X_i$ 与个人均值中心化项 $X_{it}-\bar X_i$：

$$
Y_{it}=\beta_0+\beta_W(X_{it}-\bar X_i)+\beta_B\bar X_i+u_{0i}+e_{it}.
$$

$\beta_W$ 回答“同一个人在 $X$ 高于自己平常水平时，$Y$ 如何变化”；$\beta_B$ 回答“平均 $X$ 较高的人是否也有较高的平均 $Y$”。两者可能大小不同甚至方向相反。直接把原始 $X_{it}$ 放进模型，常会混合这两个问题。模型基础与随机斜率见 [3.6 多层 / 混合效应模型](../3-statistics/multilevel)。

滞后模型还需要明确顺序。例如用 $X_{i,t-1}$ 预测 $Y_{it}$ 时，要决定是否控制 $Y_{i,t-1}$、日内周期、周末和不等间隔。一个固定的“一阶滞后”在随机提示数据中可能对应不同的实际分钟数；若过程依赖真实时间，应使用实际间隔或连续时间模型。

## 5.5.5 模型要与问题和结果匹配

- **平均轨迹**：线性或非线性增长模型估计起点、变化率及个体差异。时间零点决定截距含义；只有足够波次与覆盖范围时，复杂曲线才可识别。
- **密集重复测量**：混合效应模型或广义混合模型分开被试内/间效应，并允许随机截距、合理的随机斜率和残差自相关。
- **多变量跨波关系**：传统交叉滞后面板模型可能把稳定的人际差异混入滞后路径。若问题针对被试内偏离，可考虑随机截距交叉滞后模型或其他显式分解模型，并说明其平稳性、测量与时间间隔假设（Hamaker et al., 2015）。
- **事件或生存过程**：结果是首次发生、复发或等待时间时，应使用与删失和风险集相符的事件史模型，而不是把“是否发生”压成普通连续结果。

连续、二分类、计数和有序结果需要不同分布与链接。选择模型前画每人的时间序列、总体轨迹、观测间隔和缺失图；模型收敛不能替代这些诊断。

## 5.5.6 缺失、依从与测量反应

纵向缺失至少有三层：整个人退出、某个波次/某天缺失、提示内某题缺失。分别报告招募人数、各波次留存、计划与送达提示数、有效响应数以及响应延迟。完成率的分母必须写清，不能只报告一个总体百分比。

最大似然、多重插补或加权方法不会自动消除偏差；它们依赖缺失机制和模型正确性。把与缺失、暴露和结果有关的已观测变量纳入处理，比较完成者与退出者的基线和先前轨迹，并对选择性流失或非随机缺失做敏感性分析。不要用均值填补后把填补值当成真实观测，也不要只保留“完成率高”的人而忽略这种筛选改变了目标人群。

频繁测量本身可能改变觉察或行为。检查回答是否随研究天数、提示次数或奖励阶段系统变化；若发现反应性，把它作为限制或计划中的时间效应，而不是静默删除后期记录。

## 5.5.7 效应、不确定性与报告

效应要带时间和层级单位。例如“同一个人的压力比其个人均值高 1 个原量尺单位时，当晚睡眠时长平均少多少分钟”，比只报标准化系数更可解释。报告原始系数、95% CI、被试内与被试间标准化方式、随机效应方差和残差相关；二分类结果给预测概率或风险差，避免只给优势比。

诊断和报告至少覆盖：

- 招募、留存、计划/送达/完成记录及排除流程；
- 测量内容、提示算法、窗口、实际时间间隔、奖励和设备；
- 时间零点、中心化、滞后、协变量、随机效应和残差结构；
- 轨迹图、个体差异、残差/自相关、异常个体和对不同合理模型的敏感性；
- 主要效应及区间、预测轨迹或概率，以及外推到其他时段和人群的边界。

::: warning 常见误用
- 把观测行数当作独立样本量，忽略参与者内相关；
- 用人与人之间的差异解释同一个人的日内变化；
- 因为 $X$ 早于 $Y$ 测量，就把滞后关联写成因果效应；
- 事后尝试许多滞后、窗口和中心化方式，只报告显著组合；
- 删除低完成率参与者后仍把结果推广到所有招募对象。
:::

采样、排除、时间窗口和主要模型应在 [2.5 预注册与开放科学](../2-design/preregistration) 中预先固定，并为探索性的动态分析保留明确标签。

## 执行清单

<OutlineCard title="从时间问题到可分析数据">

1. 写清变化、被试内共变或滞后预测中的主要估计目标与时间尺度。
2. 选择波次、日记、信号或事件触发方案，并用目标人群预试负担与理解。
3. 固定提示、响应窗口、时间戳、奖励、退出和异常处理规则。
4. 建立长格式数据字典，标出参与者、时间、提示、事件和测量层级。
5. 预注册中心化、时间函数、滞后、缺失处理、随机效应与敏感性分析。
6. 报告实施日志、依从分母、效应区间、诊断以及无法支持的因果解释。

</OutlineCard>
