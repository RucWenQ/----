# 5.6 二元数据 / APIM

::: tip 本节目标
读完本节后，你能识别二元相依数据，定义行动者与伴侣效应，判断成员是否可区分，选择与结果和重复结构相符的 APIM，并报告效应区间、相依性、缺失与因果边界。
:::

## 5.6.1 为什么不能把两个人拆开分析

**二元数据**来自具有配对关系的两个成员，例如伴侣、朋友、室友、亲子或谈判双方。同一二元组成员共享环境、互相影响，也可能因配对规则而相似，因此两人的结果通常相关。若把每个人当作独立样本做普通回归，标准误和效应解释都可能错误；若把两人平均，又会丢失方向和角色信息。

先定义四个单位：

| 要素 | 需要写清什么 |
| --- | --- |
| 二元组 | 什么关系构成一组；一人能否属于多个组？ |
| 成员 | 角色是伴侣 A/B、照顾者/儿童，还是没有实质角色？ |
| 观测 | 每人一次结果，还是每人在多个时点、任务或冲突中的结果？ |
| 估计目标 | 自己的 $X$ 与自己的 $Y$、对方的 $X$ 与自己的 $Y$，或两者差异？ |

两名互不认识、只是被实验者随机配对的人也可以构成二元组，但外推对象是这种特定互动与配对机制。网络中一人同时连接多人时，二元组彼此重叠，标准 APIM 的独立二元组假设不成立，需要网络或多成员模型。

## 5.6.2 APIM 回答什么问题

**行动者—伴侣相互依赖模型**（actor–partner interdependence model, APIM）同时估计自己的预测变量和伴侣的预测变量与结果的关系。以可区分成员 1 和 2 为例：

$$
\begin{aligned}
Y_1 &= \beta_{01}+a_1X_1+p_{12}X_2+e_1,\\
Y_2 &= \beta_{02}+a_2X_2+p_{21}X_1+e_2.
\end{aligned}
$$

$a_1$、$a_2$ 是**行动者效应**：自己的 $X$ 与自己的 $Y$ 的条件关联；$p_{12}$、$p_{21}$ 是**伴侣效应**：对方的 $X$ 与自己的 $Y$ 的条件关联。两个残差允许相关，以反映模型未解释的二元相依。

例如，双方各自报告压力 $X$ 与关系满意度 $Y$。$p_{12}$ 回答“控制成员 1 自己的压力后，成员 2 的压力与成员 1 的满意度如何关联”。横断 APIM 仍是条件关联，不能仅凭显著伴侣效应断言压力从一方传播到另一方。

## 5.6.3 成员可区分还是不可区分

**可区分二元组**有研究上有意义且在所有二元组中一致的成员变量，例如亲子角色或治疗者/来访者。性别只有在样本关系结构和研究问题中能一致标识两个角色时才可用于区分；随意把成员编号为 1/2 不会产生可解释角色。

**不可区分二元组**没有这样的角色，例如同角色室友或未指定角色的朋友。分析中通常对交换成员标签应得到相同结果，因此需要对均值、方差、行动者/伴侣效应及相关结构施加相应等值约束。若理论上有角色，可先检验相关参数是否不同；未发现差异不等于证明两个角色完全相同，结论还取决于区间和检验功效。

数据整理时保留稳定的 `dyad_id`、`member_id` 和真实角色。宽格式便于结构方程模型：一行一组、两人的变量分列；成对长格式便于混合模型：每人一行，同时带自己的变量、伴侣变量和角色。无论哪种格式，都要用程序检查每组人数、重复 ID 和伴侣变量是否正确配对。

## 5.6.4 设计与抽样先于模型

样本量的主要独立单位是二元组，不是个人总数。精度还取决于二元组内相关、行动者与伴侣预测变量相关、成员可区分性、缺失、重复次数和效应大小。没有通用的“多少对足够”；应围绕主要行动者/伴侣效应、最小关注效应及区间宽度，用与计划模型一致的模拟规划，并为整组和单方流失留余量。

招募与测量需要处理以下问题：

1. 明确由谁邀请谁、双方是否独立同意，以及拒绝是否会被另一方知晓。
2. 两人尽量独立作答；记录是否同处、讨论答案或由一人代填。
3. 使用各自私密的链接和身份核验，避免向伴侣泄露敏感回答。
4. 对关系长度、共同居住、互动频率和配对来源等边界变量预先定义。
5. 若有操纵，写清随机化单位是二元组还是个人，以及一人的处理是否影响另一人。

二元研究常涉及关系冲突、暴力、健康或隐私。退出和风险响应必须允许成员单独行动，不能让共同奖励或招募流程造成强迫；伦理原则见 [2.6 研究伦理](../2-design/ethics)。

## 5.6.5 选择 APIM 的实现方式

单波、每人一个连续结果时，APIM 常用结构方程模型或路径模型：同时估计两条结果方程、成员间预测变量协方差和结果残差协方差。重复测量时，可用混合效应模型让记录嵌套于成员和二元组，并按设计加入时间、随机斜率与自相关；基础见 [3.6 多层 / 混合效应模型](../3-statistics/multilevel)。

选择还取决于结果类型：

- 连续结果可用线性 APIM，并检查残差、非线性和高影响二元组；
- 二分类、计数或有序结果需要相应链接函数，系数应转为预测概率、风险差或其他可解释量；
- 纵向 APIM 要区分稳定的人际差异和同一个人随时间的偏离，不能把两者混成一个系数；
- 一个成员同时对应多个伙伴、家庭超过两人或团队互动，需要扩展到一对多、多成员或社会关系模型。

控制变量也要成对考虑。只控制行动者年龄却忽略伴侣年龄，可能改变伴侣效应含义；同时放入高度相关的双方预测变量会增加不确定性。报告相关、共线性诊断和系数区间，不因一个方向显著、另一个不显著就断言两条效应不同。

## 5.6.6 效应模式、诊断与边界

优先报告原始量尺上的 $a$、$p$ 及 95% CI，再补充清楚标准化基准的系数或预测差异。若比较行动者与伴侣效应，应直接检验 $a-p$ 等参数约束并给区间；“一个显著、一个不显著”不是差异检验。Kenny 与 Ledermann（2010）提出可用伴侣/行动者效应关系描述二元模式，但当行动者效应接近 0 时比值会不稳定，不能机械贴标签。

诊断至少包括：

- 二元组内 $X$、$Y$ 和残差相关，确认相依性没有被忽略；
- 双方预测变量的相关与共线性、极端二元组和角色分布；
- 可区分性约束、行动者/伴侣等值约束及替代模型的敏感性；
- 连续结果的残差与线性，非连续结果的拟合、预测概率和稀疏类别；
- 重复数据的时间趋势、自相关、随机效应与记录数分布；
- 结果对单方缺失、整组流失和不同缺失假设的敏感性。

APIM 控制了双方测得的 $X$ 并反映二元相依，但不会自动控制共同原因。共同环境、关系质量和选择进入关系都可能影响双方变量。实验处理、时间顺序或纵向模型可以增加识别信息，仍需写清随机化、无未测混杂、干扰和缺失等额外假设。

## 5.6.7 缺失与报告

区分整组缺失、只缺一名成员、某成员缺某次测量和题目缺失。只分析双方均完整的二元组可能选择出更稳定或更合作的关系。全信息最大似然、多重插补或混合模型可以利用部分观测，但仍依赖缺失机制与模型；插补模型需保留角色、二元组和双方变量，不能把两人分开独立插补。

至少报告：二元组定义与招募、组数与个人数、可区分依据、双方完成流程、变量与观测层级、数据格式、模型和等值约束、协方差/随机效应、缺失处理、软件与版本。结果给行动者和伴侣效应、两者差异或计划模式、95% CI、预测值以及从关联到因果和从样本关系到其他关系的边界。

::: warning 常见误用
- 把 $2N$ 名成员当作 $2N$ 个独立样本，或只把标准误“聚类”却不定义伴侣效应；
- 随机给成员编号后，把 1 号与 2 号系数解释成真实角色差异；
- 分别跑两条回归，却不估计双方预测变量和结果残差的相依；
- 用单方完整案例替代缺失处理，不报告有多少组只完成一人；
- 把横断伴侣效应写成传染、影响或因果机制。
:::

## 执行清单

<OutlineCard title="从配对关系到 APIM 报告">

1. 定义二元组、成员角色、观测单位和主要行动者/伴侣效应。
2. 判断成员是否理论上可区分，固定 ID、角色和伴侣配对规则。
3. 按二元组规划样本量、招募、独立同意、隐私与流失处理。
4. 根据结果类型与重复结构选择 SEM、混合或广义模型。
5. 预注册等值约束、协变量、缺失、主要比较和敏感性分析。
6. 报告双方效应及区间、相依参数、诊断与因果/外推边界。

</OutlineCard>
