# 5.7 质性方法概述

::: tip 本节目标
读完本节后，你能把一个开放式心理学问题转成可执行的质性研究，选择访谈、焦点小组或观察，完成一轮资料整理与编码，解释“主题”而不是只罗列引文，并报告研究者立场、证据链和不确定性。
:::

## 你什么时候需要质性方法

质性研究适合回答“人们如何理解一件事”“一个过程怎样发生”“哪些意义和情境被量表遗漏”等问题。它把语言、互动、文件或现场记录当作资料，关注意义、过程和差异，而不是先把回答压缩成几个数。

贯穿本节的**教学示例**是：研究者想知道“第一次接受心理咨询的大学生，如何理解求助过程中的羞耻与支持”。下面的访谈片段、编码和主题均为虚构示例，不是实际参与者资料。

本页的主干取自三本入门专著：Creswell 与 Poth（2018，第 4 版）用于比较研究取向和设计选择，Braun 与 Clarke（2022）用于主题分析的编码—主题流程，Charmaz（2014，第 2 版）用于理解扎根理论的持续比较与理论取样；报告清单和取样边界再用 COREQ、SRQR 与 information power 论文补充。书籍章节编号可能随电子版排版变化，阅读时以手头版本目录为准。

它不适合单独回答“总体中有多少人这样想”“哪个干预平均提高了多少分”或“X 是否造成 Y”。这些问题通常需要概率抽样、实验或纵向设计；质性资料可以帮助生成假设、解释异质性和改进量表，但不能凭少量引文估计总体比例或证明因果。

先写出估计目标：

| 研究问题 | 更合适的资料与设计 | 不能从中推出什么 |
| --- | --- | --- |
| 学生如何描述第一次求助的转折点？ | 半结构访谈，按经历阶段追问 | 转折点在总体中的发生率 |
| 同伴如何协商“保密”边界？ | 焦点小组或互动观察 | 每位成员的独立态度 |
| 某校园项目为何在不同群体中效果不同？ | 访谈、现场记录与量化结果的混合方法 | 仅凭主题证明项目有效 |

## 最短决策路径：先选问题，再选资料

1. **确定现象和范围。** 写清人群、场景、时间段与关键概念；避免把“探索一切影响因素”当作问题。
2. **确定互动形式。** 一对一访谈适合敏感经历和个人时间线；焦点小组适合观察共识、分歧和群体语言；观察或文件分析适合研究实际行为与制度文本。
3. **确定分析取向。** 需要跨个案的经验模式，可用主题分析；需要解释过程和概念生成，可用扎根理论；需要比较明确类别或文件，可用定性内容分析；需要理解一个边界清楚的系统，可用个案研究。方法名必须和认识论、资料形式及分析步骤一致。
4. **预先规定“足够”。** 不用机械套用一个访谈人数阈值；依据问题聚焦程度、样本异质性、资料质量、分析目标和可获得信息量说明停止规则。可以参考信息量（information power）和主题充分性，并记录何时新增资料不再改变核心分析。

::: warning 先不要做的事
不要先收集一大批访谈，再临时决定研究问题和方法。开放式资料仍需要明确的抽样框、访谈范围、保密方案和分析计划，否则很难判断哪些引文支持哪些结论。
:::

## 一步步完成一个最小研究

### 第 1 步：写研究问题和取样框

把问题改写成参与者能够回答的语言，例如：“在第一次咨询前后，大学生如何解释羞耻、支持和继续求助的决定？”同时列出纳入、排除和接触路径：是否必须有第一次咨询经历？时间范围多长？是否需要同时招募中途退出者？

质性取样通常是**目的性取样**，不是为了在统计意义上代表总体，而是为了获得与问题相关的差异：最大差异取样、典型个案、关键个案、滚雪球或理论取样都要说明选择逻辑。记录未参与者、拒访和招募渠道，因为渠道会塑造资料。

### 第 2 步：设计访谈或观察提纲

提纲应从容易回答的经历问题开始，再逐步进入解释和敏感主题。避免把假设写成诱导题。

| 不够好 | 可追问的版本 |
| --- | --- |
| “你是不是因为羞耻才不去咨询？” | “从考虑求助到第一次预约，你记得哪些犹豫或转折？” |
| “咨询对你有帮助吗？” | “有没有一次让你觉得有帮助或没有帮助的具体经历？发生了什么？” |
| “大家都支持你吗？” | “你向谁提过这件事？对方怎么回应？这改变了你的下一步吗？” |

预试 1–2 次，检查问题是否能引出具体事件、完成时长是否可接受、录音和转写是否可靠。预先写好跳题、暂停、危机转介和参与者不愿回答时的回应。

### 第 3 步：安全地收集和整理资料

1. 取得伦理审批、知情同意和单独撤回渠道；敏感心理健康议题要准备风险评估与转介信息。
2. 说明录音、转写、匿名化、谁能访问原始文件、保存多久以及引文如何去除可识别细节。
3. 访谈后立即记录日期、场景、互动异常和研究者的初步反思；这份现场备忘录是分析资料的一部分。
4. 转写时保留对研究问题有意义的停顿、重音、笑声或重叠发言，并制定一致的标记规则。先用参与者编号替代姓名，再把原音频与去标识文本分开存储。

### 第 4 步：建立可审计的编码链

以教学示例的虚构片段为例：

> “我在预约页面停了很久，怕同学看见。室友说‘先去试一次’，我才把表填完。第一次谈完我还是紧张，但知道下周还有预约，就没有取消。”

可以这样从资料走向解释：

| 层级 | 示例 | 检查问题 |
| --- | --- | --- |
| 初始代码 | 担心被看见；室友鼓励；预期的连续性降低取消冲动 | 代码是否贴近原话而不过度概括？ |
| 聚合类别 | 暴露风险的想象；关系支持；把求助变成可持续承诺 | 不同片段是否都符合类别边界？ |
| 主题 | **在可控暴露中试探性地继续求助** | 主题是否有中心概念、范围和反例？ |

先逐段编码，再写代码定义、纳入/排除规则和例句。可以保留反例或“负例”，而不是为了整齐把矛盾说法删掉。第二位研究者复核可以帮助发现盲点，但“编码者一致率”不是所有质性取向的必需目标；反思性主题分析更强调研究者如何共同建构解释，代码本和一致率导向的方法则需明确不同的认识论与流程。

### 第 5 步：形成主题或理论解释

主题不是“受访者谈过的主题词”清单，而是对资料中有组织意义的解释。对每个候选主题写一页分析备忘录：中心命题、子主题、支持引文、反例、与研究问题的关系、研究者的替代解释。画主题之间的关系图，再回到完整个案检查是否断章取义。

不同取向的最小流程不同：

- **反思性主题分析**：熟悉资料 → 生成代码 → 建立候选主题 → 检查内部一致性和外部区分 → 命名与定义 → 写出解释。主题是研究者与资料互动的产物，不要求“唯一正确”的代码本。
- **扎根理论**：持续比较资料、代码和备忘录，随着分析推进进行理论取样，逐步形成能解释过程的概念。若没有理论取样和概念建构，不要仅因使用“开放编码”就称为扎根理论。
- **定性内容分析**：先定义概念类别和单位，按规则编码并比较案例或材料；可以报告类别出现的次数作为描述，但次数不是总体比例，也不替代语境解释。
- **个案研究**：限定案例边界，整合访谈、文件、观察等多种证据，建立时间线和竞争解释；不能把单一案例的机制直接推广为普遍规律。

### 第 6 步：检查可信度和边界

可信度不是把质性研究伪装成量化研究。根据取向选择合适的检查：

- **三角互证**：比较不同资料来源、时间点、研究者或理论视角，说明它们一致、互补还是冲突；不把“多来源一致”自动当作真理。
- **参与者反馈**：邀请参与者评论描述是否贴切，说明谁反馈、如何处理异议；反馈不是让参与者替研究者批准最终理论的投票。
- **同伴讨论与审计轨迹**：保存提纲版本、代码定义、主题图、备忘录、排除理由和分析决策。
- **反思性**：交代研究者的立场、与场域的关系、可能的权力差异，以及这些因素如何影响提问、互动和解释。
- **负例与厚描述**：主动寻找不符合主模式的资料，给出足够情境让读者判断可迁移性，而不是只展示最生动的一句引文。

## 结果如何写和交付

每个结果主题都应回答四件事：它的中心主张是什么、由哪些资料支持、有哪些变化或反例、它对研究问题意味着什么。引文要短、去标识、带参与者编号和必要的情境信息；不要用一串引文代替分析。

方法部分至少交代：研究取向及理由、场域和研究者角色、纳入与招募、样本特征（含未参与者信息）、资料收集时长与提纲、转写和匿名化、编码/分析步骤、软件与版本、反思与质量检查、伦理审批和数据保存。COREQ（访谈/焦点小组）和 SRQR 可作为报告清单；它们是检查遗漏的工具，不是研究质量的评分阈值。

结果中不要把“有 7 人提到”写成总体比例；若报告出现次数，说明分母、编码单位和它只用于资料内描述。把“参与者认为”“本资料显示”与“导致”“证明”区分开。若质性结果与量化结果整合，先说明两种资料如何连接（例如先质性生成量表项目，再用独立样本验证），不要把一段引文当作效应量。

::: warning 常见误用与排错
- 用便利样本的引文代表所有学生，或把饱和说成一个不加条件的固定人数；
- 把访谈提纲问题直接当作主题，不检查跨个案模式和反例；
- 只报告软件名称，不保存代码本、备忘录、版本和分析决策；
- 为追求“客观”而隐藏研究者立场，或把一致率当作所有质性取向的质量证明；
- 在公开引文、音频或转写中保留能够反推身份的课程、地点、组织和事件细节；
- 发现危机风险时继续追问却没有暂停、转介和单独退出流程。
:::

## 一个可复用的执行清单

<OutlineCard title="从开放问题到可追溯结果">

1. 写出研究问题、案例边界、估计目标和不适用的推论。
2. 选择访谈、焦点小组、观察或文件，并说明取样差异和停止规则。
3. 预试提纲与记录设备，固定同意、保密、转介和撤回流程。
4. 建立去标识长表：`case_id`、资料来源、时间、转写版本、代码和备忘录链接。
5. 逐段编码、比较个案、记录反例，形成有定义和证据链的主题或概念。
6. 用反思、同伴讨论、三角互证或参与者反馈检查解释，并保留审计轨迹。
7. 按 COREQ/SRQR 检查方法报告，给出引文情境、限制、可迁移性和后续验证路径。

</OutlineCard>
