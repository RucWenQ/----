# 5.4 量表研究

::: tip 本节目标
读完本节后，你能根据构念、用途和目标人群选择或改编量表，规划翻译与认知访谈，检查内部结构、信度和测量不变性，并透明报告计分、删题与不确定性。
:::

## 5.4.1 先决定分数要用来做什么

量表研究的核心不是找到一套“已经验证”的题目，而是建立一条证据链：在<span class="kw">特定人群、语言、情境和用途</span>下，观测到的回答能否支持预定的分数解释。效度针对分数的解释与用途，不是量表名称的永久属性。换语言、改题干、删题、改回答选项或换到新群体后，都要重新说明证据是否仍适用。

先写清以下要素：

| 要素 | 需要回答的问题 |
| --- | --- |
| 构念 | 要测的是状态、特质、行为频率，还是临床/管理决策指标？边界是什么？ |
| 用途 | 描述样本、比较群体、预测结果、筛查，还是评价干预变化？ |
| 目标人群 | 年龄、语言、文化、教育程度与使用场景是什么？ |
| 观测单位 | 一名参与者一次作答，还是同一人多次作答、多人评价同一对象？ |
| 分数 | 总分、分量表、潜变量或类别判定；缺失题目如何处理？ |
| 主要证据 | 内容、回答过程、内部结构、与外部变量的关系及使用后果需要哪些证据？ |

量表总分通常是多个题目的函数。一条作答记录同时由参与者和题目决定；整套量表由多人作答时，题目与参与者通常是交叉的，而参与者才是主要抽样单位。重复测量还会加入嵌套于参与者的时间点。把题目作答数当成彼此独立的样本量会夸大信息量。

## 5.4.2 选现成量表、改编还是开发

优先检索构念定义相符、目标人群接近、计分透明且有原始题目来源的量表，再决定工作量。

| 路径 | 适合情况 | 不能省略的工作 |
| --- | --- | --- |
| 直接使用 | 语言、群体、情境和用途与既有证据高度接近 | 核对既有证据的适用性、版本、授权、题目与计分；在当前样本报告分布和信度 |
| 翻译或改编 | 构念相同，但语言、文化、媒介或措辞需要调整 | 双向核对含义、认知访谈、结构检验；跨组比较前检查不变性 |
| 开发新量表 | 现有量表遗漏关键内容，或目标构念确有不同 | 构念界定、题库生成、专家与目标人群审查、预试、结构探索与独立确认 |

不要因为现成量表在当前样本中某个系数不理想，就边看结果边删题，直到得到好看的数字。删题可能缩窄构念覆盖，且会让当前数据同时承担“开发”和“验证”两种任务。若必须调整，记录每一步及理由，并在独立样本中确认新版本。

使用前还要核对授权和版本。能在论文附录中看到题目，不等于允许公开复制、翻译或商业使用；保存授权依据、原版题号、译文版本号和计分键。

## 5.4.3 翻译与跨文化改编

逐字回译只能发现部分语言差异，不能保证构念在新文化中含义相同。以下是符合 ITC 指南原则的一种可执行流程，不是唯一合格程序：

<OutlineCard title="改编工作流">

1. 取得授权，界定目标人群、用途和需要保持的构念边界。
2. 根据项目条件选择双译者、委员会等翻译设计；译者应熟悉两种语言、构念和目标文化，并记录题目、指导语与回答选项的协商过程。
3. 用回译、双语专家审查或其他独立核对发现意义偏移；不要把回译一致当作终点。
4. 对目标人群做认知访谈，询问他们如何理解、回忆、判断和选择答案。
5. 小样本预试题目分布、漏答、极端集中、完成时间和技术问题。
6. 在正式样本检验结构、信度和与外部变量的关系；跨语言或群体比较前检验测量不变性。
7. 保存原文、每轮译文、修改理由、专家意见和最终版本，公开可分享的材料。

</OutlineCard>

年龄、职业或平台语境的改写也属于改编。例如把“在学校”改为“在工作中”可能改变构念的行为域，不能只称为文字润色。

## 5.4.4 从题目到内部结构

先检查题目方向、合法取值、缺失、类别频数和反向计分，再进入因子分析。Likert 题是有序分类观测；类别很少或分布偏斜时，应考虑适合有序数据的相关与估计方法，而不是默认把题目当作连续正态变量。

- **探索性因子分析（EFA）**用于结构尚不确定时比较因子数与载荷模式。因子数应结合理论、平行分析、残差和可解释性，而不是只用“特征根大于 1”。
- **确认性因子分析（CFA）**评估数据与事先指定的载荷、因子关系是否相容，不能证明该结构唯一或真实。报告估计量、载荷与区间、因子相关、残差和多个拟合信息；单个拟合指数越过经验阈值不等于模型正确。
- **题目打包**会隐藏题目层面的错配，可能让不同模型看起来都拟合良好。除非有清楚的测量模型和目的，不要用打包修补拟合。

同一数据上反复探索、删题、加误差相关，再把最终 CFA 称为“验证”，会低估不确定性。样本允许时使用独立开发与确认样本；不能拆分时，应明确这是探索性模型，并通过新样本或复现研究确认。

## 5.4.5 信度、效度与可比性

内部一致性描述题目在给定测量模型和样本中的共同变异。应说明所报告的 $\omega$ 类型及其测量模型，或选择与模型相符的其他估计，并给出 95% CI；Cronbach's $\alpha$ 可作为补充，但同样依赖假设。高 $\alpha$ 或 $\omega$ 可能来自题目多或内容重复，不能证明单维性与效度。重测、评分者一致性和密集测量中的被试内信度回答不同问题，不能互换。基础概念见 [2.2 测量](../2-design/measurement)。

效度证据至少考虑：

- **内容与回答过程**：题目是否覆盖构念，目标人群是否按预期理解和作答；
- **内部结构**：因子、载荷和计分方式是否与理论一致；
- **与外部变量的关系**：收敛、区分、已知组差异或预测关系是否符合事先预期；
- **分数使用与后果**：若用于筛查或决策，错误分类、阈值和群体差异会造成什么后果；由构念遗漏或无关变异导致的后果会影响效度论证，其他政策或伦理后果也要评价，但不能一概当作效度证据。

跨群体、语言或时间解释潜均值差前，通常应依次检查构型、载荷和截距层面的**测量不变性**；有序题则应在所用参数化下检验载荷、阈值等约束。比较观测总分也不能绕过计分和题项功能的可比性。不变性不足不意味着量表“完全无效”，但会限制可比较的参数；可以报告部分不变模型、项目层差异或只比较仍有依据的关系。不要在未建立可比性时把总分差直接解释为构念差。

## 5.4.6 样本量、缺失与诊断

“每题 5 人”或“至少 200 人”不是通用样本量规则。所需信息取决于因子数、载荷强度、题目类别、模型复杂度、目标参数精度、群体数和缺失。先确定主要参数与可接受的区间宽度，再用与计划模型一致的模拟或功效分析；跨组不变性还要保证每组都有足够信息。通用规划原则见 [2.4 取样与功效分析](../2-design/sampling-power)。

漏答处理要区分整份缺失与个别题缺失。按手册规则计分并报告规则；不要默认用个人均值补题。模型估计或多重插补仍依赖缺失机制假设，应纳入与缺失和结果有关的变量，并对不同合理处理做敏感性分析。

诊断时至少检查：

- 题目分布、地板/天花板、类别稀疏、反向题异常和局部依赖；
- 载荷、交叉载荷、残差与高因子相关，是否提示题目重复或构念未区分；
- $\omega$、重测或评分者一致性的区间，而不是只贴“合格/不合格”标签；
- 群体或时间上的不变性、差异题项功能，以及结果对删题和估计方法的敏感性；
- 总分、分量表或潜变量结论是否与预定计分和实际结构一致。

## 5.4.7 报告与执行清单

至少报告量表来源和版本、授权、语言、题目数、回答选项、计分方向、总分规则、施测环境、目标人群、样本量、缺失与删题。结果应给题目/分数分布、结构参数、信度及区间、效度证据和失败的诊断。比较观测分数时，报告原始量尺差、标准化差及 95% CI；比较潜变量时，报告潜均值差及区间，并说明识别方式、参照组和标准化方法。两者都要写清所依赖的可比性证据。

::: warning 常见误用
- 把“某篇论文验证过”当作在所有人群和用途中的永久许可证；
- 用高 $\alpha$ 证明单维性，或用删题后的高系数证明量表更有效；
- 在同一数据中探索、修改并确认模型，却不标明数据驱动过程；
- 未检验可比性就比较语言、性别、文化群体或不同时间的均值；
- 只报告拟合阈值和 `p` 值，不报告载荷、区间、残差与实际计分规则。
:::

分析计划可在 [2.5 预注册与开放科学](../2-design/preregistration) 中固定；潜变量与不变性模型的统计入口见 [3.7 SEM / PLS-SEM](../3-statistics/sem)。
