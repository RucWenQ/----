# 5.2 实验室实验

::: tip 本节目标
读完本节后，你能把实验设计写成可重复执行的协议，设置随机化、盲法和设备检查，识别试次嵌套与实施偏离，并用效应量、不确定性和诊断结果报告实验。
:::

## 5.2.1 实验室控制了什么

实验室实验把处理分配、刺激呈现、测量环境和时间顺序尽量固定，用来回答“在这套程序下，随机分配到不同处理会怎样改变结果”。核心因果对比来自随机分配，而不是来自实验发生在房间里。没有随机操纵的实验室测量仍可能只是关联研究。

较强控制可以减少无关变异、精确记录过程并复现实验条件；代价是样本、任务、互动和时间尺度可能离现实场景较远。<span class="kw">内部效度与外部效度不是一条只能二选一的轴：先保证处理对比可解释，再用不同样本、材料和场景检验推广。</span>

开始编程前，先写出：

- **处理与对照**：具体改变什么，两个条件共同经历什么；
- **主要结果**：量尺、时间点、计分规则和最小关注效应；
- **随机化单位**：参与者、组、场次或试次；
- **观测结构**：组间、组内、重复试次或多人互动；
- **估计目标**：意向性处理效应、条件均值差、反应概率差或计划交互；
- **边界**：实验室程序能够和不能代表的现实处理与行为。

因果设计的前置概念见 [2.3 实验设计基础](../2-design/experimental-design)。

## 5.2.2 把设计写成可执行协议

一个合作者若只看协议，应该能完成同样的招募、接待、分配、呈现、测量和收尾。建议给每个场次生成唯一编号，并把以下内容固定下来。

| 环节 | 协议中要写清 |
| --- | --- |
| 招募 | 目标总体、渠道、纳入/排除、重复参与控制、补偿 |
| 接待 | 同意版本、指导语、等待时间、设备与环境设置 |
| 分配 | 随机序列如何生成、由谁保存、何时揭示条件 |
| 呈现 | 刺激文件版本、顺序/平衡、时长、允许的中断 |
| 测量 | 主要与次要结果、计分、反应窗口、缺失代码 |
| 收尾 | 操纵检查位置、事后说明、退出、补偿和支持信息 |
| 日志 | 设备故障、误操作、偏离、破盲和参与者疑问 |

### 先导测试不是缩小版显著性检验

先导测试用于发现流程错误、估计时长、检查量尺范围、测试数据保存和演练异常处置。小先导样本的效应估计不稳定，不应只因“方向不好”就改主要假设，也不宜作为正式研究唯一的样本量输入。样本量应依据最小关注效应、精度或其他可审计理由，见 [2.4 取样与功效分析](../2-design/sampling-power)。

正式收集前做一次端到端“干跑”：从随机分配到导出匿名数据，确认变量名、条件编码、时间戳、失败状态和数据字典一致。用虚拟 ID 测试，不要在正式数据中留下测试记录。

## 5.2.3 随机化、盲法与顺序

- **随机序列**应由可复现的生成器产生并保存；若按性别、场次或基线风险分层，应在分配前确定层变量和区组规则。
- **分配隐藏**防止接待者提前知道下一个条件并影响入组；它与参与者或实验员在分配后的盲法不是同一件事。
- **实验员盲法**无法实现时，使用逐字指导语、自动呈现和最少自由裁量，并记录实验员 ID 与破盲事件。
- **组内设计**需随机或平衡顺序，预先规定练习试次、间隔与携带效应的检查方式。
- **多人互动实验**要说明随机化和干预发生在人、二元组还是小组层级；同组成员的结果通常相关。

随机化不要求实验结束后所有基线变量都完全相等。应报告分配流程和各组描述，不要按基线显著性反复重分组或事后选择协变量。预先指定的强预测基线变量可用于提高精度。

## 5.2.4 操纵、需求特征与数据质量

处理实施失败可能来自刺激版本错误、程序分支错误、实验员偏离或参与者根本没有接触到处理。把这些问题分开记录：

1. **程序校验**：保存条件、刺激 ID、呈现时长和错误码；正式开始前核对每个分支。
2. **理解与注意**：题目应测量完成任务所需的信息，而不是用晦涩陷阱筛人；阈值和排除用途要预先规定。
3. **操纵检查**：说明它测的是感知、理解还是理论中介，安排在不会污染主要结果的位置。
4. **需求特征**：在不欺骗参与者承担关键风险的前提下，使用掩护任务、标准化互动或事后猜测题评估研究目的是否过于明显。

不要把操纵检查当作因果链已经成立的证明，也不要默认删除“没有感知到操纵”的参与者。检查若受处理影响，按它筛选相当于按处理后的变量选择样本，可能破坏随机化解释。主要分析通常按原分配进行，依从性或感知条件分析需单独说明假设。

伦理审查、欺骗和事后说明要求见 [2.6 研究伦理](../2-design/ethics)。

## 5.2.5 观测结构与分析

一个参与者完成 100 个试次，不等于有 100 个独立参与者。试次嵌套在参与者内；同一刺激被多人看到时，反应还可能跨材料相关。分析模型应与处理和抽样层级一致。

- 每人一个连续结果：报告条件均值、均值差、95% CI 和标准化效应；
- 每人多次连续反应：使用参与者层相关结构，必要时同时建模材料；
- 二分类正确/错误：报告绝对概率差，并用二项模型处理重复试次；
- 反应时：先画分布和错误率，固定合理的数据清理规则；不要只对反应时取均值而忽略速度—准确权衡；
- 组或二元互动：标准误和效应定义必须反映组内依赖。

检查残差、极端值、天花板/地板效应、条件方差、场次趋势、设备或实验员差异和缺失模式。模型不收敛时，记录失败表现和每次修改；不要不停简化模型直到出现显著结果。主要效应应回到原始量尺解释，标准化效应作为补充，并给出不确定性。

::: warning 常见误用
- 把试次数当作独立样本量，造成伪重复和过窄区间；
- 边收数据边看显著性，再决定是否继续招募或新增排除；
- 只报告成功的条件、结果或清理方案；
- 把“处理组显著、对照组不显著”当作组间差异，应直接检验计划对比；
- 因为任务在实验室内可控，就把短时任务效应外推为长期现实行为。
:::

## 5.2.6 交付一份可复现实验

<OutlineCard title="正式收集前后检查">

1. 冻结协议、主要结果、随机化、停止和排除规则。
2. 用虚拟参与者跑遍所有条件、顺序、退出和设备失败分支。
3. 保存刺激、程序、依赖版本、随机种子、变量字典和场次日志。
4. 每日核对记录数、条件分配、缺失字段与错误码，不查看组间主要结果。
5. 按预注册分析，同时报告偏离、排除、效应量、区间和诊断。
6. 共享可运行材料与代码；受伦理限制的数据提供字典、模拟数据或访问流程。

</OutlineCard>

心理学定量研究的报告项目可对照 APA JARS；预注册的最低字段见 [2.5 预注册与开放科学](../2-design/preregistration)。
