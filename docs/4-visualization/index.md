## 本章先解决什么问题？

作图不是把显著结果涂成醒目的颜色，而是把**数据结构、统计问题、估计量和不确定性**交给读者核对。读者带着“我该画什么、误差条代表什么、怎样导出不失真”的问题来，本章给出一条从选择到验收的路径。

贯穿示例是一份明确标为**模拟数据**的干预 × 时间长表：40 名被试、两个条件、两个时间点。它只用于练习数据映射和代码，不代表真实研究结果。复杂重复测量、抽样权重或模型预测仍需回到相应统计方法页。

## 最短决策路径

1. 写一句读图问题：比较分布、变化、关联，还是展示模型估计？
2. 写出观测单位和变量类型：被试、试次、时间点或研究；连续、分类、计数或效应量。
3. 先选统计方法和估计对象，再选点、线、区间、瓦片或路径图。
4. 决定颜色、形状和分面各自承载的含义；把不确定性定义写进图注。
5. 先画原始数据，再叠加与模型一致的摘要或预测；最后按目标尺寸导出并检查。

## 开始前需要什么？

- 能看懂长表：一行是什么观测、哪些列是识别变量、哪些列是结果变量。
- 知道均值、置信区间和模型预测不是同一件事；不确定时先看[统计章节](/3-statistics/)。
- 安装 R/ggplot2 或 Python/seaborn/matplotlib，并把版本写入项目日志。
- 有一个固定的项目目录，保存清理数据、脚本、图形输出和图注文本。

## 交付前的共同检查

- [ ] 图型确实回答研究问题，没有把装饰当作证据。
- [ ] 每个点、线、面和区间都能追溯到数据或模型；重复测量没有被当作独立观测。
- [ ] 颜色、图例、分面、坐标和注释的含义写清楚，黑白和色觉缺陷预览仍可读。
- [ ] 轴标签有单位或范围，视窗没有无意删除观测；统计变换和区间定义写在图注。
- [ ] 代码、数据版本、软件版本、随机种子和导出参数已归档；PDF/SVG/PNG 打开检查过。

完成这条路径后，再把图交给导师或统计顾问做最后的设计与推断复核。图能帮助沟通结果，但不能替代研究设计、模型诊断或伦理审查。
