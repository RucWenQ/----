## 一、变量与变量类型

**变量**（variable）：是在不同观测之间会取不同值的特征。常量（如圆周率）不是变量（仿佛废话hhhh），所有被试都填同一个数（比如向一年级的学生发放问卷，测量他们的年级，获得的结果“一年级”）的也"事实上"不是变量——因为没有变异，统计上无法分析。

**观测**（observation）：之所以强调不同“观测”，而不是不同“样本”/“被试”，是因为对同一个样本/被试在不同时间的测量也可以构成不同观测。

**特征**：变量是对象的属性，而不是对象本身。“张三”是一个对象，“张三”的“性别”“年龄”等特征可以构成变量。

### 1. 变量的四级分类

S. S. Stevens 在 1946 年提出的四分类沿用至今。它本质上是在回答：**在这个变量上做哪些数学运算才有意义？**

| 类型             | 关键属性           | 允许的运算                    | 心理学常见变量                         |
| ---------------- | ------------------ | ----------------------------- | -------------------------------------- |
| **定类**Nominal  | 类别区分，无序     | 计数、众数、卡方              | 性别、民族、实验组别                   |
| **定序**Ordinal  | 类别有序，间距未知 | 上述 + 中位数、百分位、秩相关 | 学历                                   |
| **定距**Interval | 间距相等，无绝对零 | 上述 + 加减、均值、标准差     | 智商                                   |
| **定比**Ratio    | 间距相等，有绝对零 | 上述 + 乘除、比值             | 反应时、年龄、收入、行为次数、量表得分 |

::: tip 小技巧
各级变量允许的运算方式是向**上**兼容的，比如定序变量可以用定类变量的运算方式，反之则不行。

区分定距和定比变量的关键点在于是否有绝对零值，比如智商是一个以100为平均值，15为标准差的正态分布，没有绝对零值；反应时、收入等则可以有绝对零值
:::

::: warning 李克特量表到底是定序还是定距？

- **严格地说，单条目的 5 / 7 点李克特题是定序变量**——"非常同意"和"同意"之间的距离，未必等于"同意"和"中立"之间的距离。
- 但是，**在实践中**，往往假定通过李克特量表测得的人们态度、意见的不同方向和程度差异具有等距性。
- 此外，**多条目量表的合成分**（比如自尊量表 10 题求平均）<span class="kw">通常被当作定距甚至定比变量</span>处理。模拟研究表明这样做对 t / 回归 / SEM 的偏差通常很小。
- 单条目结果若用 t 检验、Pearson 相关需要更谨慎；可以同时报告非参方法（Mann-Whitney、Spearman）做敏感性分析。
  :::

### 2. 另一个独立的变量分类维度：离散 vs. 连续

这与 Stevens 的四级分类是**正交**的。前者关心数值特征，后者关心统计特征。

- **离散变量**（discrete）：取整数或可数值。例：答对题数、行为次数。
- **连续变量**（continuous）：在区间内可取任意值。例：反应时。

定类一定是离散的；定比可以是连续（反应时）或离散（孩子数）。

### 3. 为什么变量类型是重要的？

因为类型直接决定了**能用哪些分析**。把性别（定类）放进 Pearson 相关里没意义；把反应时（右偏的定比）当 IQ 那样直接做 t 检验同样在统计上是错误的。本节末尾附上了“变量类型-统计检验”速查对照表。

## 二、自变量与因变量

**自变量**（IV, independent variable）是研究者**操纵或选择**、被假设为"原因"或"预测变量"的东西。
**因变量**（DV, dependent variable）是研究者**测量**、被假设为"结果"的东西。

::: tip 实验研究 vs. 相关研究

- 在**实验研究**中，IV 是实验者**主动操纵**的（启动条件、奖励金额、实验组别），DV 是测量得到的——这种结构允许做因果推断。
- 在**相关 / 横断研究**中，IV 只是被研究者**选作“预测变量”**（如人格、收入），DV 是被预测的**结果变量**。<span class="kw">即使统计上 X 显著预测 Y，设计本身不允许下"X 导致 Y"的因果结论。</span>
- 在表述中，**相关 / 横断研究**，只允许使用预测变量和结果变量的表述，不能用自变量和因变量的表述。
  :::

### 1. 自变量的常见要求

按"能否做因果推断"分两类：

**(A) 实验性自变量**——可以操纵的：

- **可操纵性**（manipulability）：研究者能把它"调"到不同水平。无法被操纵的（性别、人格、年龄）严格说不算实验 IV。
- **充分变异**：至少两个水平，否则无法比较。
- **理论依据**：操纵要对应到理论构念上。比如想操纵"权力感"，需要让被试回忆一段拥有权力的经历，，而不是回忆“道德”“助人”等无关的经历，要能让人确实感到自己有更大权力。
- **操纵检验**（manipulation check）：用一个独立测量验证操纵真的奏效。**这是审稿人必查项**。
- **排除混淆**：操纵 X 时不能附带操纵 Y。两组之间除了 X 不应该有别的系统差异。
- 通常配合**随机分配**，避免选择偏差，尽可能确保在准实验变量上，各个组别的分布是接近的，比如避免实验组全是男性，控制组全是女性。

**(B) 准实验/被试变量**——不可操纵的：

- 性别、年龄、人格特质、文化背景。
- 这些只能被"选择"或观察。<span class="kw">使用这些变量做因果推断一定要慎之又慎，论文中应说明为相关性结论。</span>

### 2. 因变量的常见要求

DV 的好坏几乎完全决定了一项研究的可信度。底线是三个属性：

- **信度**（reliability）：测一千次结果稳定。常用 Cronbach's α、重测信度、评分者一致性。
- **效度**（validity）：测的就是你声称在测的东西。含内容效度、构念效度、效标效度。
- **敏感性**（sensitivity）：能区分出实验操纵带来的差异。有两类常见问题：

::: danger 天花板与地板效应

- **天花板效应**（ceiling effect）：题太简单，几乎所有人都拿满分，组间无法拉开。
- **地板效应**（floor effect）：题太难/罕见行为，几乎所有人都是 0 或最低分。
- 出现这两种之一，<span class="kw">即使你的操纵真的有效，DV 也无法把效应"显示"出来</span>。预实验和功效分析阶段就要排查。
  :::

::: danger 其他常见问题

- **要求特征**（demand characteristics）：被试猜到了实验目的并迎合。
- **社会赞许性**（social desirability）：被试报告自己"应该是"的样子，而非真实情况。
- **共同方法偏差**（common method bias）：IV 和 DV 都用同一种方法（比如同一份问卷自评）测量，会人为抬高相关。
  :::

## 三、中介变量与调节变量

这两个是社会心理学中容易混淆且相对复杂的概念。一言以蔽之：

- **中介变量**（mediator, M）回答 **"X 通过什么影响 Y"**——机制问题。
- **调节变量**（moderator, W）回答 **"X 在什么条件下对 Y 的影响会发生变化"**——边界条件问题。

### 1. 中介变量

中介变量**位于因果链条的中间**：X → M → Y。

$$
\text{IV} \xrightarrow{a} M \xrightarrow{b} \text{DV}, \qquad a*b = \text{间接效应}
$$

**例子**：

> 高 **自我效能感**（X）→ 投入更多 **努力**（M）→ 取得更好的 **学业成绩**（Y）

这里 M（努力）就是 X 影响 Y 的"通道"。如果控制了 M，X 对 Y 的效应应当变小（部分中介）或消失（完全中介）。

::: tip 哪些变量"可以"当中介

- **理论上和时间上都位于 X 与 Y 之间**的变量。
- 经典候选：心理过程（认知评估、情绪反应）、行为（具体动作、决策）、生理反应（皮质醇、心率）。
- M 必须 **能被 X 影响** 且 **能影响 Y**。
  :::

::: danger 哪些变量"不能"当中介

- **测量时间在 X 之前**的变量——违背时间先后逻辑。
- **本质上和 X 是同一个构念**，只是换了个测量方式（这只是测量问题，不是中介）。
- **稳定的人口学/特质变量**（性别、年龄、人格）——一般不可能"被 X 改变"，**它们更适合当调节变量**。
- 与 Y **概念上重叠或定义包含**（比如把"数学成绩"当成"学业成绩"的中介，学业成绩本身包含数学成绩）。
  :::

### 2. 调节变量

调节变量**改变 X→Y 关系的强度或方向**：在不同水平的 W 下，X 对 Y 的效应不同。

$$
Y = b_0 + b_1 X + b_2 W + b_3 (X \times W) + \varepsilon
$$

只要 $b_3$（交互项）显著，就有调节效应。

**例子**：

> **工作压力**（X）→ **情绪耗竭**（Y），但 **社会支持**（W）调节这一关系：
> 在低社会支持下，压力强烈推高耗竭；在高社会支持下，这一效应减弱。

调节关系的可视化通常是 simple slopes 图：高 W 一条线，低 W 一条线，看两条斜率是否不同（更详细的内容见 [3.5 中介与调节](./mediation-moderation)）。

::: tip 哪些变量"可以"当调节

- 与 X-Y 关系**逻辑独立**，且能改变其强度/方向的变量。
- 典型候选：人口学变量（性别、年龄、文化）、人格特质（神经质、自尊）、情境变量（任务难度、时间压力）、实验组别。
  :::

::: danger 哪些变量"不能"当调节

- **变异太小**的变量（比如 95% 都是同一个值）——交互项几乎无法估计。
- **会随 X 改变**的变量——违反"调节变量独立于 X"的前提。
  :::

### 3. 一个口诀

| 问的问题                  | 角色   | 示意      |
| ------------------------- | ------ | --------- |
| **为什么** X 会影响 Y？   | 中介 M | X → M → Y |
| **什么时候** X 才影响 Y？ | 调节 W | X × W → Y |

衍生：**有调节的中介**（moderated mediation）= 调节作用作用在中介路径的某一段；**有中介的调节**（mediated moderation）= 调节效应通过一个中介传递。详见 [3.5](./mediation-moderation)。

## 四、数据结构 决定 分析方法

在数据分析的任何一个阶段都要牢记以下逻辑。

### 1. 五个台阶的逐级映射

```
理论（theory）
   ↓ 演绎
假设（hypothesis）：可证伪的具体预测
   ↓ 操作化
操作性定义（operational definition）
   ↓ 落实
变量（variables）：IV / DV / M / W / 协变量
   ↓ 设计
研究设计 + 数据结构（design + data structure）
   ↓ 分析
统计检验（statistical test）
   ↓ 结果
回到理论：支持 / 不支持 / 修正
```

**理论**（theory）是一组关于"世界如何运作"的相互关联的命题。例：自我决定理论。

**假设**（hypothesis）是从理论里推出来的、**可证伪的具体预测**。"自主感（X）正向预测内在动机（Y），且这一关系被环境支持感（W）调节"——这是一个可证伪的假设。

**操作性定义**（operational definition）是把抽象构念落到可以观测/测量的程序上。<span class="kw">同一个构念可以有多种操作化，每种操作化都是一组关于"什么是什么"的规定/约束。</span>例如"焦虑"可以操作化为 BAI 量表得分，也可以操作化为皮质醇水平，还可以操作化为公开演讲任务中的紧张表情时长。

**变量**是被操作化后的构念。同一个研究里，要明确每个变量的：

- **角色**：IV / DV / M / W / 协变量
- **类型**：定类 / 定序 / 定距 / 定比
- **形式**：连续 / 离散 / 二分

**研究设计**决定了**数据结构**。横断 vs. 纵向、被试间 vs. 被试内、单层 vs. 多层（学生嵌套于班级）、是否有重复测量——这些都会改变数据的"形状"。

**数据结构**反过来决定了你**只能用哪些分析方法**。这一步往往是最容易忽略的——只要看到"两组比较"就用 t 检验，但忽略了数据是不是嵌套的、是不是重复测量的、DV 是不是连续的、正态的。

### 2. 一个完整链条的样例

::: details 例：自尊—焦虑—幸福感的中介研究

**理论**：自我价值理论认为高自尊提升心理健康。

**假设**：自尊（X）正向预测幸福感（Y），且这一效应通过降低焦虑（M）实现。

**操作性定义**：

- 自尊 = Rosenberg 自尊量表 10 题均分
- 焦虑 = BAI 21 题均分
- 幸福感 = SWLS 5 题均分

**变量**：

- IV：自尊（连续，定比/定距处理）
- M：焦虑（连续）
- DV：幸福感（连续）

**研究设计**：横断在线问卷，_N_ = 300，所有变量同时测量。

**数据结构**：长 1 行/被试 × 宽 3 个变量 + 人口学，无嵌套，无重复测量。

**分析方法**：

- 步骤 1：描述性统计 + 相关矩阵（见 [3.1 描述性统计](./descriptive)）
- 步骤 2：PROCESS Model 4 + 5000 次 bootstrap 计算 ab 间接效应及其 95% CI
- 步骤 3：报告间接效应、直接效应、总效应

**回到理论**：若 ab 显著且包含 0 不在 CI 内，支持"焦虑作为中介"的机制说法；同时讨论横断设计对因果推断的限制。

:::

### 3. 顺序写反了会怎样

实践中常见的错误顺序是：

> 数据已经收完了 → 看哪个分析显著 → 倒推一个理论说得通的故事

这就是 **HARKing**（Hypothesizing After the Results are Known）。它会人为膨胀 I 类错误率，是复现危机的核心元凶之一。<span class="kw">健康的顺序永远是从理论到分析，而不是反过来</span>。

<!-- 预注册（[2.5 预注册](/2-design/preregistration)）就是为了把这个顺序锁住。 -->

### 4. 为什么"研究设计 → 数据结构 → 分析"不能跳

跳过数据结构这一环，常导致下面这些经典错误：

- 把嵌套数据（学生嵌套于班级）当独立观测做，I 类错误率被低估。
- 重复测量数据用独立样本 t 检验，损失功效。
- 二分 DV 用线性回归（应该用 logistic 回归）。
- 把潜变量直接用合成分而不是 SEM，忽略了测量误差。

正确做法：**先想清楚数据"长什么样"——是否分层、单次测量还是重复测量、变量是什么类型，再考虑/决定"这种结构对应什么分析"**。

## 五、实操对照表：变量类型 → 分析方法

下面这张表是这一节的"查表入口"。它把"自变量类型 × 因变量类型"映射到最常见的分析方法。

| 自变量             | 因变量     | 典型分析                          | 出现章节                        |
| ------------------ | ---------- | --------------------------------- | ------------------------------- |
| 二分类             | 连续       | 独立样本 _t_ 检验 / 配对 _t_ 检验 | [3.2.1](./t-test)               |
| 三类及以上         | 连续       | 单因素 ANOVA                      | [3.2.2](./anova)                |
| 多个分类（含交互） | 连续       | 多因素 ANOVA                      | [3.2.2](./anova)                |
| 多个分类           | 多个连续   | MANOVA                            | [3.2.3](./manova)               |
| 分类               | 分类       | 卡方检验 / Fisher 精确检验        | [3.3](./chi-square)             |
| 连续               | 连续       | Pearson 相关 / 一元回归           | [3.4](./regression)             |
| 多个连续/分类      | 连续       | 多元回归                          | [3.4.2](./regression)           |
| 多个 + 分类自变量  | 连续       | 加哑变量的回归                    | [3.4.3](./dummy-coding)         |
| 含中介路径         | 连续       | PROCESS Model 4 / SEM             | [3.5.1](./mediation-moderation) |
| 含交互项           | 连续       | 调节回归 + simple slopes          | [3.5.2](./mediation-moderation) |
| 含嵌套结构         | 连续       | 多层线性模型 (HLM / MLM)          | [3.6](./mixed-effects)          |
| 多个连续           | 二分类     | Logistic 回归                     | [3.4](./regression)             |
| 多个潜变量         | 多个潜变量 | 结构方程模型 SEM                  | [3.7](./sem)                    |

::: info 怎么使用这张表

- 从 DV 类型出发，比从 IV 出发更不容易出错。
- 表里没覆盖的情形：纵向数据、生存数据、计数数据、文本数据——这些会在专门小节展开。
- 如果你的设计找不到对应的分析方法，**多半是设计本身可以再简化**，而不是要去找一个更冷门的统计。
  :::
