# 3.2 差异分析

::: tip 本节目标

- 理解差异分析的统一逻辑：信噪比 = 组间差异 / 组内波动
- 根据自变量和因变量的结构，选对方法（t / ANOVA / MANOVA）
- 区分独立样本与配对设计，避免最常见的分析错误

:::

## 差异分析的应用场景

差异分析旨在回答一个核心问题：**几组人在某个连续变量上的均值是不是真的不一样**。如果**组间差异 > 组内波动**，就有理由认为均值确实不同。

## 方法速查表

根据自变量和因变量结构，直接定位该用哪个：

| 自变量结构          | 因变量   | 用什么                            | 去这里            |
| ------------------- | -------- | --------------------------------- | ----------------- |
| 一个二分类（两组）  | 一个连续 | **独立样本 t 检验** / 配对 t 检验 | [3.2.1](./t-test) |
| 一个多分类（≥3 组） | 一个连续 | 单因素 ANOVA                      | [3.2.2](./anova)  |
| 多个分类（含交互）  | 一个连续 | 多因素 ANOVA                      | [3.2.2](./anova)  |
| 多个分类            | 多个连续 | MANOVA                            | [3.2.3](./manova) |

## 先分清：配对还是独立？

这是差异分析里最容易搞错的一步——选错了，结果直接无效。

- **同一批人** 测两次（前测—后测、操纵前—操纵后）→ 配对 t 检验（paired t-test）。
- **两批互不相关的人** 各测一次 → 独立样本 t 检验。
- **同一对里的两个人**（夫妻、双胞胎）→ 也属于配对结构，至少要做配对 t 或考虑用多层模型。
