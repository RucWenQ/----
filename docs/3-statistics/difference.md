# 3.2 差异分析

::: tip 本节目标

- 理解差异分析的统一逻辑：把估计差异与它的不确定性比较
- 根据自变量和因变量的结构，选对方法（t / ANOVA / MANOVA）
- 区分独立样本与配对设计，避免最常见的分析错误
- 报告均值（或均值向量）差、置信区间和效应量，而不是只报 p 值

:::

<OutlineCard title="本节的三个部分">

- [**3.2.1 t 检验**](./t-test) — 两组均值比较
- [**3.2.2 ANOVA**](./anova) — 多组均值比较 · 单因素 & 多因素
- [**3.2.3 MANOVA**](./manova) — 多个因变量同时分析

</OutlineCard>

## 差异分析的应用场景

这里的差异分析主要回答：**在给定的研究设计下，条件、组别或时间点之间的均值（或均值向量）差异是否与抽样误差相容**。t 检验和 ANOVA 把估计到的均值差异与它的不确定性比较；ANOVA 的 F 统计量可理解为模型解释的变异相对于误差变异的大小。MANOVA 则把多个相关结果作为一个整体检验，不能把它简单当成“多做几次 ANOVA”。观察到样本均值不同本身还不够，还要结合置信区间、效应量和研究设计判断。

## 方法速查表

根据自变量和因变量结构，直接定位该用哪个：

| 条件结构                    | 观测关系             | 因变量   | 用什么                       | 去这里            |
| --------------------------- | -------------------- | -------- | ---------------------------- | ----------------- |
| 两个条件                    | 两组相互独立         | 一个连续 | **独立样本 t 检验**          | [3.2.1](./t-test) |
| 两个条件 / 时间点           | 同一对象重复或一一配对 | 一个连续 | **配对 t 检验**              | [3.2.1](./t-test) |
| 一个样本与有依据的参考值比较 | 观测彼此独立         | 一个连续 | **单样本 t 检验**            | [3.2.1](./t-test) |
| 一个因素，三个及以上条件    | 观测相互独立         | 一个连续 | 单因素 ANOVA                 | [3.2.2](./anova)  |
| 多个分类因素（可含交互）    | 观测相互独立         | 一个连续 | 多因素 ANOVA                 | [3.2.2](./anova)  |
| 一个或多个分类因素          | 观测相互独立         | 多个连续 | MANOVA                       | [3.2.3](./manova) |

::: warning 这张表不是只看变量个数
同一批人测三次，不是把三列直接当作普通单因素 ANOVA；学生嵌套在班级，也不是相互独立的观测。重复测量、嵌套、缺失和方差不齐都会影响具体模型。先画清每一行数据代表谁、哪些观测来自同一对象，再选检验；必要时转到混合效应模型。
:::

## 先分清：配对还是独立？

这是差异分析里最容易搞错的一步——若把依赖观测当成独立观测，标准误和置信区间就可能与设计不匹配。

- **同一批人** 测两次（前测—后测、操纵前—操纵后）→ 配对 t 检验（paired t-test），它检验的是每个人的差值；没有随机对照或其他识别条件时，前后差异不等于干预的因果效应。
- **两批互不相关的人** 各测一次 → 独立样本 t 检验。
- **同一对里的两个人**（夫妻、双胞胎）→ 观测通常相关。如果问题只是比较两个固定角色的均值，可以使用配对 t 检验；如果要研究双方变量如何相互影响，应考虑 APIM、多层模型或其他二元数据方法，而不是把所有二元数据都简化成配对 t。

::: tip 下一步

确认好你的数据结构和分组数量后，按下面的最短路径操作：

1. 写下要比较的方向（例如“纳入组 − 排斥组”或“后测 − 前测”）以及实际观测单位。
2. 标出同一人、同一对、同一班级或同一时间序列中的依赖观测；若存在依赖，先看表外的重复测量/混合模型入口。
3. 核对结果变量是否有连续量尺意义、缺失和离群点，再进入对应子章节运行检验。
4. 从输出中同时抄录估计差异、95% 置信区间、效应量、检验统计量和自由度，并在报告中注明设计与因果边界。

:::
