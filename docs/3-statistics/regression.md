## 一、为什么这一章是统计学的"主轴"

社心方向的数据分析，**95% 的情形都能装进一个统一的框架**——**一般线性模型**（General Linear Model, GLM）：

$$
Y = b_0 + b_1 X_1 + b_2 X_2 + \dots + b_k X_k + \varepsilon
$$

到目前为止你学过的所有方法，<span class="kw">在数学上都是这个公式的不同特例</span>：

| 你以前学的方法 | 在 GLM 里长什么样 |
| --- | --- |
| **独立样本 t 检验** | $Y = b_0 + b_1 X$，其中 $X$ 是 0/1 哑变量（两组） |
| **单因素 ANOVA**（k 组） | $Y = b_0 + b_1 D_1 + \dots + b_{k-1} D_{k-1}$，其中 $D_i$ 是哑变量 |
| **双因素 ANOVA** | 主效应 + 哑变量交互项的回归 |
| **ANCOVA** | 哑变量 + 连续协变量的回归 |
| **Pearson 相关** | 一元回归 $Y = b_0 + b_1 X$ 的标准化版本 |
| **一元回归** | 一个连续 $X$ 的 GLM |
| **多元回归** | 多个 $X$ 的 GLM |

这意味着——<span class="kw">回归不是 t/ANOVA 的"补充"，而是更基础的母题</span>。t 检验、ANOVA 是回归在"自变量为分类变量"时的特殊语言。当代统计学教学（包括美国心理学博士项目）越来越偏好"先教回归，再把 t/ANOVA 作为特例介绍"，原因正在于此。

::: tip 这个观点为什么重要
看清这一点后，几个原本"看起来很不同"的工作会突然合一：
- **中介、调节** → 都是回归（[3.5](./mediation-moderation)）
- **多层模型** → 也是回归（[3.6](./mixed-effects)）
- **SEM** → 一组联立的回归（[3.7](./sem)）
- **Logistic 回归** → 把 GLM 的 Y 换成对数几率

掌握了回归，就掌握了这一章和后面三章的"通用语法"。
:::

## 二、相关分析 vs. 差异分析的比较

到目前为止你学的 t 检验、ANOVA、卡方都属于**差异分析**——研究**几组人在某变量上是否不同**。本章讲的相关与回归则是**关系分析**——研究**两个（或多个）变量是否一起变化**。

它们在很多方面相似，但适用场景泾渭分明。

### 1. 一张表看清异同

| 维度 | 差异分析（t / ANOVA / 卡方） | 关系分析（相关 / 回归） |
| --- | --- | --- |
| **典型问题** | A、B 两组的 *Y* 是否不同？ | *X* 和 *Y* 是否一起变化？ |
| **IV 类型** | 分类（必须） | 连续（典型） / 也可分类（哑变量） |
| **DV 类型** | 连续 | 连续 |
| **效应方向** | 通过比较组均值看出 | 通过 *r* 或 *b* 的正负号看出 |
| **效应大小** | Cohen's *d* / η² | Pearson *r* / R² / β |
| **典型设计** | 实验研究（操纵分组） | 横断 / 问卷研究 |
| **能扩展到多 IV 吗** | 能（多因素 ANOVA） | 能（多元回归，更灵活） |
| **能处理交互吗** | 能（ANOVA 交互） | 能（回归乘积项） |
| **能处理协变量吗** | 能（ANCOVA） | 能（多元回归，更自然） |

### 2. 它们的相似之处比想象多

很多人以为"相关"和"差异"是两套独立的工具，其实它们高度同源：

- **t 检验 ≡ 点二列相关**（point-biserial correlation）：把分组变量编码 0/1，与连续 DV 求相关，*r* 的 *p* 值与 t 检验完全相同。
- **ANOVA ≡ 多元回归**（用哑变量编码 IV）：两者结果完全等价。SPSS 里 GLM 模块和 Regression 模块跑同一个数据会给同样的 *F* 和 *p*。
- **方差解释比例**统一为 *R²*（或 *η²*）：在 GLM 里，*R²* 就是 *η²*。

::: details 一个验证：t 检验是相关的特例
取 t 检验里"被排斥 vs 被纳入"的数据。
- 用独立样本 t 检验（[3.2.1](./t-test) 例子）：*t*(58) = 6.06, *p* < .001
- 把 condition 编码 0 (被纳入) / 1 (被排斥)，与 need_threat 求 Pearson *r*：*r* = .622, *p* < .001
- 满足 $t^2 = F = \frac{r^2 (n-2)}{1-r^2}$，三者**完全等价**

不同名称只是不同视角下的不同语言。
:::

### 3. 怎么选：分组比较还是连续视角？

实操决策的核心是：**你的自变量本身是分类的还是连续的？**

| 你的 IV | 推荐做法 |
| --- | --- |
| **天然分类**（实验组别、性别、诊断类别） | 差异分析（t / ANOVA） |
| **天然连续**（年龄、收入、量表分） | 相关 / 回归 |
| **可二者皆可**（如收入分为高中低） | 优先用连续！见下面警告 |

::: danger 中位分割（median split）的诱惑——别上当
社心方向有个长期顽疾：把连续变量人为地切成"高 / 低"两组（用中位数为界），然后跑 t 检验或 2×2 ANOVA。这样做看起来"清爽"，结果可发可读。但 MacCallum 等 (2002) 那篇经典批判文章揭露了几个严重问题：

- **平均损失约 30% 的统计功效**——把连续信息扔了一半。
- **可能产生虚假的交互效应**——两个连续 IV 都做中位分割后做 2×2 ANOVA，本来不存在的交互可能"出现"。
- **可能掩盖真实的非线性关系**。
- **结论依赖于你的样本中位数**——换一批被试，分组阈值就变，结论也变。

<span class="kw">如果你的 IV 是连续的，就用相关 / 回归处理。不要为了"做 ANOVA 看起来更熟"而切两半</span>。
:::

## 三、相关与一元回归：同一件事的两种说法

这是本章衔接 3.4.0 → 3.4.1 的关键。

### 1. 数学上的一致性

对一组连续的 (X, Y) 数据：

- **Pearson 相关系数**（标准化指标）：

$$
r = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2 \sum (Y_i - \bar{Y})^2}}
$$

- **一元回归方程**：

$$
\hat{Y} = b_0 + b_1 X
$$

它们之间存在**直接的等价关系**：

$$
b_1 = r \times \frac{SD_Y}{SD_X}, \qquad \beta = r
$$

也就是说：

- 一元回归里**未标准化系数** $b_1$ 是 *r* 乘以 SD 比。
- 一元回归里**标准化系数** $\beta$ 就**等于** *r*。
- 一元回归的 *R²* = 相关系数的平方 = $r^2$。
- 检验"$b_1 \neq 0$"的 *t* 值与检验"$r \neq 0$"的 *t* 值**完全一致**。

### 2. 但它们回答的问题不同

虽然数学等价，**叙述视角**不同：

| | 相关分析 | 一元回归 |
| --- | --- | --- |
| 视角 | 对称——*X* 和 *Y* 地位相同 | 不对称——*X* 预测 *Y* |
| 输出关注 | 一个 *r* 值 + 显著性 | 截距、斜率、预测值、残差 |
| 典型问题 | "它们相关吗？相关有多强？" | "给定 *X*，*Y* 大约是多少？" |
| 适合的研究目的 | 探索性、描述性 | 预测性、解释性 |
| 能扩展吗 | 不太能（顶多分组求相关） | **能**——多元回归、含分类 IV、含交互、含中介 |

::: tip 怎么决定叫"相关"还是"回归"
- 你只想说"这两个变量相关"→ 报告 Pearson *r*
- 你要做预测、解释、控制其他变量、扩展为中介调节模型 → 用回归
- 论文 Results 节的"描述统计 + 相关矩阵表"里报告 *r*；"假设检验"段落里报告回归系数

<span class="kw">两者数学上是同一回事，但回归是更通用的工具</span>。本章的设计也按这个思路：先用 3.4.0 把 *r* 学清楚，再用 3.4.1 把它扩展为回归框架，3.4.2/3.4.3 把这个框架做大。
:::

## 四、本章结构地图

接下来 4 个小节按"由浅入深、由简入繁"的顺序展开：

| 小节 | 核心问题 | 加入的新元素 |
| --- | --- | --- |
| **3.4.0 相关分析** | *X* 和 *Y* 一起变化吗？ | 两个连续变量的关联强度 |
| **3.4.1 一元回归** | 给定 *X*，*Y* 大约是多少？ | 斜率、截距、预测、残差 |
| **3.4.2 多元回归** | 控制其他变量后 *X* 还预测 *Y* 吗？ | 多个连续 IV、共线性、模型选择 |
| **3.4.3 哑变量回归** | 怎么把分类 IV 装进回归？ | 哑变量编码、ANOVA = 回归的事实 |

学完这四节，你就能用统一的回归框架解释 t 检验、ANOVA、ANCOVA、相关分析——并且自然过渡到 [3.5 中介与调节](./mediation-moderation) 和 [3.6 多层模型](./mixed-effects)。

## 五、决策表：什么时候用回归、什么时候用差异分析

| 你的情形 | 推荐方法 | 出现章节 |
| --- | --- | --- |
| 两组（实验组 vs 对照） + 连续 DV | t 检验 / 哑变量回归 | [3.2.1](./t-test) / 3.4.3 |
| 三组及以上 + 连续 DV | ANOVA / 哑变量回归 | [3.2.2](./anova) / 3.4.3 |
| 两个连续变量的关联 | Pearson 相关 / 一元回归 | 3.4.0 / 3.4.1 |
| 连续 IV 预测连续 DV，控制其他变量 | 多元回归 | 3.4.2 |
| 多个连续 + 分类 IV 共同预测 | 多元回归（含哑变量） | 3.4.3 |
| 两个分类变量的关联 | 卡方检验 | [3.3](./chi-square) |
| 实验设计 + 想看个体差异如何调节效应 | 调节回归（含交互） | [3.5.2](./mediation-moderation) |
| 想检验中介机制 | 中介回归 | [3.5.1](./mediation-moderation) |

::: warning 一个值得重申的原则
**遇到连续 IV，不要为了"做 ANOVA 简单"而切成高/低两组**。当代统计哲学的共识是：信息越保留越好，分类越少越好。回归可以做差异分析能做的所有事，反过来则不然。
:::
