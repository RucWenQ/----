## 本章导读：你现在卡在哪一步？

科研工具不是软件清单，而是一条可复核的工作链。先用问题定位入口，再把原始材料、版本、权限和输出保存下来：

| 你要完成的任务 | 先读 | 最小产物 |
| --- | --- | --- |
| 找到并筛选文献 | [1.1 文献检索](./literature-search) | 检索式、日期、筛选记录和 DOI |
| 管理全文与引用 | [1.2 Zotero 全工作流](./zotero) | 去重后的文献库、附件和备份 |
| 选择分析环境 | [1.3 数据分析软件](./stats-software) | 变量字典、锁定的依赖与分析脚本 |
| 获得 AI 草稿或检查帮助 | [1.4 大模型与 AI 辅助](./ai-llm) | 提示、原始输出、人工核验与披露记录 |
| 部署行为实验 | [1.5 实验程序工具](./experiments) | 版本化程序、试次字段字典和预试日志 |

| 校外访问数据库 | [1.7 网络与 VPN](./vpn) | 官方入口、授权范围和故障记录 |

## 一条不容易丢东西的最短路径

1. **定义问题和权限。** 在下载或上传前写清研究问题、数据是否含个人信息、伦理批准和团队访问范围；必要时先看[研究伦理](../2-design/ethics)。
2. **保存原始输入。** 原始 PDF、导出 CSV、问卷版本和程序包保持只读，文件名带日期或版本号，不把截图当作唯一记录。
3. **让每一步可重做。** 记录检索式、软件/包版本、随机种子、提示词、清洗规则和人工决策；把“最后一次修改”变成可追踪的提交或变更日志。
4. **先用小样本验收。** 用公开或明确标注的模拟数据检查导入、编码、分析和导出，再接触正式数据。
5. **交付前做人工闸门。** 打开原文核引用，运行代码，检查图表与表格，确认没有泄露密钥或参与者信息，并让合作者按同一份说明复现一次。

## 何时停下来求助？

出现以下情况时，继续换软件通常不会解决问题：数据结构与模型不匹配、参与者可能被重新识别、版权或机构许可不清、实验计时主张未在目标硬件验证、代码与输出无法对应，或团队对排除规则没有共识。把最小复现材料、版本和错误信息整理好，再向导师、伦理/数据管理员、图书馆或统计顾问求助。

::: warning 版本与服务会变化
本章各页记录了核查日期或软件版本，但菜单、价格、模型名称和机构入口仍可能更新。以官方文档、学校政策和目标期刊当前要求为准；不要把教程中的临时界面截图当作长期规则。
:::
