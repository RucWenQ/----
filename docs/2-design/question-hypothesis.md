# 2.1 研究问题与假设

::: tip 本节目标
读完本节后，你能把宽泛的兴趣收敛为一个可回答的研究问题，明确变量、观测单位和比较对象，写出带方向与边界的假设，并在收集数据前说明主要效应量和不确定性。
:::

## 2.1.1 从兴趣到研究问题

好的问题不是“我想研究焦虑”，而是指定**对象、情境、时间和比较**：在什么人群中，什么暴露或操纵与什么结果有关，比较什么条件，观察期多长？先区分研究问题的类型：

| 问题 | 典型变量与结构 | 适合的结论 |
| --- | --- | --- |
| 描述 | 一个总体或样本的水平、分布、变化 | 估计均值、比例或分布，不比较原因 |
| 关联/预测 | 连续或分类的 (X) 与 (Y)，每个观测单位一行 | 条件关联、预测误差和外推边界 |
| 因果 | 随机分配的处理 (A)，潜在结果 (Y(1),Y(0)) | 平均处理效应及其适用人群 |
| 机制/异质性 | 处理、结果与中介 (M) 或调节变量 (W) | 预先定义的机制线索或条件差异 |

把“为什么”拆成可观察的构念和估计目标（estimand）。例如，“短视频是否影响注意力”至少要改写为：“在随机分配观看时长的本科生中，观看 10 分钟与观看教育材料相比，任务反应时的平均差异是多少？”若无法指定比较、结果测量或时间点，问题还没有准备好进入统计分析。

## 2.1.2 变量、观测单位与假设

在方案中列出：

1. **观测单位**：人、试次、家庭或班级；重复试次并不自动等于更多独立被试。
2. **变量角色**：处理/自变量 (A)、结果 (Y)、协变量 (X)、中介 (M)、调节变量 (W)。写明量尺、编码、测量时间和缺失代码。
3. **主要比较**：两组差、回归斜率、风险比，或纵向变化的组间差异。一个主要问题只指定一个主要结果和时间点，其他结果标为次要或探索性。
4. **观测结构**：独立、配对、嵌套或纵向。结构决定标准误和模型，而不是由软件菜单决定。

假设应能被数据反驳，并写清方向、单位和边界。连续结果的示例是“处理组在第 4 周的平均抑郁量表分数比对照组低；目标参数为 (Delta=E[Y(1)-Y(0)])，预期 (Delta<0)”。不要把“有显著差异”当作假设：它没有说明效应多大，也没有说明在哪个总体和时间点成立。方向没有理论依据时，使用双侧假设而不是事后按结果改成单侧检验。

## 2.1.3 把假设连接到分析

在分析计划中同时写出效应量和不确定性：均值差配 95% 置信区间，标准化均值差配原始量尺差异，相关问题配 (r) 或回归系数，二分类结果配风险比或优势比。效应量的解释要回到测量单位和最小重要差异；(p) 值只描述在零假设及模型成立时数据的相容程度，不能代替效应大小或复制概率（Wilkinson & APA Task Force, 1999）。

列出关键假设及失效处理：随机分配是否成功、缺失是否与结果有关、量表是否在目标样本中可用、是否存在干扰或多重比较。若结果是观察性关联，应使用“关联”“预测”而不是“导致”；若改变了主要结果、排除规则或模型，应保留原计划并标为探索性。

::: warning 常见误用
先看数据再选择假设、把协变量显著解释为混杂已被控制、把中介分析当作机制证明，都会把描述性结果包装成因果结论。假设应在看到主要结果前锁定；未预注册的分析可以做，但要如实标注其探索性。
:::

## 2.1.4 一页式问题模板

可在方案或预注册中填入：

> 在 **[总体/情境]** 中，将 **[处理或预测变量]** 与 **[对照/基线]** 比较，**[主要结果]** 在 **[时间点]** 的 **[估计目标]** 是多少？主要效应量为 **[量尺]**，95% CI 由 **[模型/稳健方法]** 给出；若 **[关键假设]** 不满足，则采用 **[预先指定的替代方案]**。

先画出变量关系图，再检查每个箭头是否对应一个可测量的比较。这样可以发现循环论证、遗漏的时间顺序和把同一被试的多次观测误当独立样本等问题。
