# 2.6 研究伦理

::: tip 本节目标
读完本节后，你能识别社会心理学研究中的主要风险，准备伦理审查与知情同意材料，区分匿名化和去标识化，并在招募、欺骗、补偿、在线研究与数据共享中设置保护措施。
:::

## 2.6.1 伦理不是审批表，而是持续责任

涉及人的研究通常围绕三项原则展开：**尊重个人**要求自愿且可理解的同意；**有利与不伤害**要求比较风险和收益并降低可避免伤害；**公正**要求研究负担与受益机会不因便利或弱势身份而不合理分配。

适用规则取决于研究地点、机构、资助方、样本与数据类型。中国《涉及人的生命科学和医学研究伦理审查办法》（国卫科教发〔2023〕4号）适用于其规定范围内的机构和研究；社会行为研究还需遵守所在单位伦理委员会及数据管理要求。<span class="kw">研究者不应自行宣布“免审”；应在招募、获取可识别数据或实施研究程序前，由有权限的机构确定审查路径。</span>

批准也不是终点。方案、招募文本、补偿、风险、数据用途或主要程序发生实质变化时，应按机构规则先申请变更；偏离、投诉、隐私事件和未预期伤害应及时记录并报告。

## 2.6.2 从参与者视角评估风险

社会心理学研究的风险不只包括身体伤害，还包括：

- **心理风险**：羞耻、焦虑、创伤唤起、被排斥体验；
- **社会与声誉风险**：身份、立场或关系暴露；
- **经济与法律风险**：就业、保险、纪律处分或违法信息泄露；
- **隐私风险**：直接标识符、行为轨迹或多个变量组合后可重新识别；
- **权力风险**：教师招募自己的学生、管理者招募下属，导致拒绝变得困难。

逐项判断风险的严重程度、发生概率、持续时间和可逆性，再安排降低措施：减少不必要问题、允许跳题、设置中止条件、提供支持资源、把招募与评分/管理关系分开，并限制谁能接触可识别数据。“最小风险”的正式含义和审查类别依司法辖区而异，不要凭研究者直觉套用。

样本选择也需要理由。只因容易招募而反复让某一群体承担研究负担，或在研究可能使另一群体受益时系统排除他们，都可能违反公正原则。涉及未成年人、认知能力受限者、受羁押者或强依赖关系中的参与者时，应采用机构要求的额外同意或保护程序。

## 2.6.3 知情同意要让人真正能决定

一份可用的**知情同意**至少说明：

1. 研究者身份、研究性质和参与者将做什么；
2. 时长、随机分组、录音录像或敏感问题等关键程序；
3. 可合理预见的风险、不适与直接受益是否存在；
4. 自愿参加、可跳题和可退出，以及退出后的补偿与数据处理；
5. 补偿金额、支付条件和额外费用；
6. 数据如何保存、谁能访问、保存多久、是否共享或二次使用；
7. 研究与伦理问题的联系方式。

同意文本应使用目标参与者能理解的语言；电子勾选不是理解的证据。高风险或复杂研究可加入简短理解题，并允许参与者提问。补偿应补偿时间与负担，避免大到足以压倒风险判断；退出时的支付规则应事先明确，不能把完成全部程序作为不合理的强制条件。

### 欺骗与事后说明

欺骗只有在研究问题重要、非欺骗替代方案不足、风险可接受且已获事前批准时才可能成立。不能欺骗参与者接受会影响其参与意愿的严重风险。研究结束后通常应尽快**事后说明**真实目的、欺骗内容与必要性，恢复自主决定；在可行且经批准的情况下，说明是否可以撤回其数据。延迟说明或不说明必须有具体理由和额外保护。

::: warning 不要这样做
不要先实施欺骗，再以“如果知道目的就会有需求特征”为理由补做伦理说明。方法学便利本身不构成伦理批准。
:::

## 2.6.4 匿名、去标识化与数据共享

**匿名数据**意味着研究团队无法合理地把记录连回个人；**去标识化或假名化数据**只是把姓名等标识符替换为编码，如果仍保存对应表，就仍可能重新识别。把姓名列删掉不等于匿名化：年龄、学校、职位、时间戳、位置和原文引语的组合也可能指向个人。

<OutlineCard title="数据保护最小流程">

1. 只收集回答研究问题所需的数据，并为每项敏感变量写明用途。
2. 把身份对应表与研究数据分开保存，使用加密和最小权限控制。
3. 在同意书中写清保存期限、共享范围、二次使用和删除边界。
4. 共享前评估直接与间接重识别风险，必要时聚合、删减或采用受控访问。
5. 预先制定泄露、误发和账号失守的响应与报告流程。

</OutlineCard>

开放科学不要求公开不该公开的数据。若伦理承诺、法律、平台条款或重识别风险限制开放，可共享分析代码、变量字典、合成数据、聚合结果或申请式访问说明。数据管理计划应与知情同意、预注册和论文中的共享声明一致。

## 2.6.5 在线研究与公开数据

网页可访问不等于参与者合理期待被研究。使用论坛、社交媒体或聊天记录时，应同时评估平台条款、群体规范、内容敏感性、引语能否被搜索定位、用户是否为未成年人，以及联系或发表会不会增加伤害。删除用户名后逐字引用敏感帖子，仍可能通过搜索重新识别作者。

在线实验还要记录机器人或重复参与者控制、设备与可访问性限制、跨境数据传输、第三方平台收到哪些数据。质量控制不能以秘密收集更多身份信息为代价；需要 IP、设备标识或定位信息时，应在方案和同意中说明并设置最短保存期限。

## 2.6.6 执行清单

### 招募前

- 完成方案、风险收益评估、招募材料、同意/事后说明、补偿和数据管理计划；
- 获得适用的伦理审查决定并保存版本号、日期与批准材料；
- 让团队接受相应培训，限制可识别数据访问；
- 对高风险环节演练中止、转介和事件报告流程。

### 研究期间

- 使用获批版本同意材料，记录同意、退出、方案偏离与投诉；
- 不因招募困难擅自扩大样本、提高补偿或增加数据用途；
- 监测未预期风险，发生事件时先保护参与者，再按制度报告。

### 研究结束后

- 按承诺完成事后说明、补偿与支持信息；
- 按批准方案保留、去标识化或销毁身份信息；
- 只作证据支持的结论，公开利益冲突和伦理限制；
- 发表图片、案例或原文引语前再次评估可识别性。

::: danger 严重错误
伦理批准通常不能追溯性地覆盖未经批准已经实施的研究。若发现未获批收集、同意失效或数据泄露，应停止相关活动、保护参与者并立即联系本机构伦理与数据治理部门，而不是自行补写文件。
:::
