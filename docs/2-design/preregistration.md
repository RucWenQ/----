# 2.5 预注册与开放科学

::: tip 本节目标
读完本节后，你能写出一份可执行的预注册，区分预注册、Registered Reports 与材料/数据共享，并在计划改变时留下透明、可追溯的偏离记录。
:::

## 2.5.1 预注册解决什么问题

**预注册**是在研究结果未知时，把带时间戳的研究计划保存为不可静默改写的记录。它把“事先计划的验证性分析”与“看到数据后的探索”区分开，减少结果变量替换、灵活排除、选择性报告和事后提出假设却写成事前假设的空间。

预注册不会自动让假设合理、测量有效或样本有代表性。含糊的预注册也不能限制研究者自由度。<span class="kw">价值不在于提前写过一份文档，而在于未知结果时已经把关键决策写到别人能够复现。</span>

最佳时间点通常是在正式数据收集前。若使用已有数据，应说明数据是否已经存在、团队成员接触过哪些变量或结果，以及预注册发生在何种访问之前；这种做法通常称为 analysis plan preregistration，不能假装数据从未被看过。

## 2.5.2 一份可执行的最低清单

预注册应覆盖会改变结论的分岔点，而不是堆背景综述。

| 模块 | 至少写清 |
| --- | --- |
| 研究问题与假设 | 每条假设、方向、对应结果与核心对比 |
| 设计 | 条件、随机化单位、盲法、测量时间点、操纵与对照 |
| 样本 | 目标总体、招募渠道、纳入/排除、样本量依据、停止规则 |
| 变量 | 主要/次要结果、量表计分、反向题、合成规则、时间窗 |
| 分析 | 模型、效应量、对比编码、协变量、交互、多重性处理 |
| 数据问题 | 缺失、异常值、不依从、失败操纵检查与重复观测 |
| 决策规则 | 哪个结果支持、反驳或不能区分假设 |
| 透明度 | 材料、代码、数据和元数据如何共享；不能公开时说明限制 |

以下差别决定预注册是否可执行：

| 含糊写法 | 可执行写法 |
| --- | --- |
| “排除异常值” | “在每个条件内，反应时低于 200 ms 的试次删除；受试者有效试次低于 70% 时排除” |
| “做回归分析” | “以总分为连续结果，拟合含处理、中心化基线分数及其预定交互的线性模型；主要估计量为处理系数” |
| “样本量约 200” | “每组 100 名可分析受试者；达到 200 人或 2026-10-31 先到者停止，损耗另行记录” |
| “必要时控制变量” | 明列每个协变量、测量时间及进入模型的理由 |

探索性分析不必穷尽，也不应伪装成事先计划。把主要分析写得足够具体，再说明哪些问题留给探索即可。

## 2.5.3 从草稿到注册

<OutlineCard title="预注册工作流">

1. 依据研究问题、测量和功效计划起草分析方案。
2. 用少量先导数据检查流程和代码，但不据此挑选显著结果。
3. 让未参与起草的合作者按文档模拟执行，找出含糊决策。
4. 在 OSF、AsPredicted 或领域平台提交不可静默覆盖的时间戳版本。
5. 保存注册链接、版本、提交日期和材料快照，再开始正式收集或分析。
6. 维护偏离日志；论文中把计划分析、偏离分析和新增探索分开报告。

</OutlineCard>

OSF 适合附带较长方案、文件与版本；AsPredicted 提供简短的结构化问题。平台只是载体，模板选择应服从研究设计。注册前要确认链接权限、是否有 embargo、哪些附件会公开，以及匿名审稿时如何提供只读版本。这些平台功能会更新，本页所列入口核查日期为 **2026-08-15**。

## 2.5.4 计划改变时怎么做

现实研究会发生设备故障、招募困难、量表计分错误或模型不收敛。改变本身不是问题，隐去改变才会误导读者。

- **结果未知时发现问题**：创建带时间戳的新版本，保留原版本，并写明改变理由和发生时间；
- **已经看过结果后改变**：不要覆盖原计划，把新分析明确标为偏离或探索，并同时给出原计划结果；
- **无法执行原模型**：报告失败表现和诊断，说明替代模型改变了哪个估计目标或假设；
- **新增排除或协变量**：分别展示预注册分析与新增分析，避免只保留更有利的版本。

论文中的偏离表可以只有四列：原计划、实际做法、改变时间、理由。预注册不是承诺永不思考，而是让读者知道哪些判断发生在结果之前。

## 2.5.5 不要混淆三种开放实践

- **预注册**：研究者自行在结果未知时固定计划；是否发表仍可能受结果影响。
- **Registered Reports**：期刊在结果产生前审查研究问题与方法；Stage 1 获得原则性接收后实施，Stage 2 主要检查方案遵循、质量与结论是否匹配证据，而不是结果是否显著。
- **开放材料、代码与数据**：让别人检查或复用研究产物；它可以与预注册结合，但不是同一件事。

开放科学也不等于所有资料无条件公开。知情同意、伦理审批、版权、隐私和数据保护优先；不能公开个体数据时，可提供变量字典、分析代码、模拟数据、聚合结果或受控访问流程，并说明限制。

::: warning 常见误用
- 在收集完数据或看过主要结果后才注册，却不披露时间点；
- 只写假设，不写样本停止、排除、变量构造和分析模型；
- 把“没有偏离预注册”当成结果正确的证据；
- 只报告预注册中显著的结果，省略其他主要结果；
- 把所有未预注册分析贬为无效。探索可以产生重要发现，但需要正确标注并在新数据中检验。
:::
