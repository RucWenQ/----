# 2.2 测量：信度·效度·操纵检验

::: tip 本节目标
读完本节后，你能为构念选择可辩护的指标，区分信度与效度，按观测结构报告测量不确定性，并设计不把操纵检验误当作因果证据的检查流程。
:::

## 2.2.1 先定义构念，再选择指标

测量问题回答的是“这个观测分数在多大程度上支持对构念的解释”，不是“量表的相关系数够不够高”。先写出构念定义、目标人群、测量时间和理论上应相关或不相关的变量，再决定采用自陈、行为、反应时或生理指标。记录题目版本、计分方向、反向题、总分规则和语言版本；改动题目或删题会改变测量对象，不能只在结果部分交代。

把每个观测分数 (X) 看作真分数 (T) 与误差 (E) 的组合：(X=T+E)。信度描述在给定条件下误差的相对大小，效度则是证据支持某种分数解释与用途的程度（Messick, 1995）。同一量表可以在某样本中内部一致性高，却不能支持跨群体比较或因果操纵的解释。

## 2.2.2 信度：报告估计而不是贴标签

- **内部一致性**：(omega) 或 (alpha) 反映题目共同变异的模型化估计。单因子、近似等值的题目和局部独立等条件影响解释；(alpha) 高不证明单维，也不证明效度。优先报告估计值、95% CI、题目数和样本，而不是使用“一般 (alpha>.70)”的硬阈值。
- **重测信度**：同一构念在两次测量的稳定性。时间间隔要与构念预期变化匹配；状态性构念的低相关可能是真实变化，不一定是测量失败。
- **评分者一致性**：分类或连续评分需明确评分者、盲法和一致性指标（如 Cohen's (kappa) 或 ICC），并报告缺失和分歧处理。

信度估计依赖样本和测量条件，不能把一个样本的系数当作量表的永久属性。若数据是多层或重复测量，先确认估计是否把被试内和被试间变异混在一起；必要时使用多层信度或分层模型。

## 2.2.3 效度证据与测量不变性

效度是累积证据：内容覆盖是否充分，内部结构是否符合理论，与相关构念的收敛/区分关系是否合理，以及分数与外部标准的关系是否支持预定用途。效度证据不能由一次显著相关“证明”。跨语言、性别或时间比较前，检查测量不变性：通常依次比较构型、载荷、截距（或阈值）约束；不变性不足时，限制比较目标或报告部分不变模型，并说明识别假设。

报告时给出原始量尺的均值、标准差和区间；标准化分数只用于可比性，不要掩盖量尺的临床或实践含义。测量误差会衰减关联并扩大预测不确定性，因此效应量解释要结合信度和最小重要差异。

## 2.2.4 操纵检验的正确位置

操纵检验是确认处理是否改变了预期心理状态的辅助测量。例如，实验操纵“威胁”后，可测量被试主观威胁感，但该检验本身可能受到需求特征影响。预先指定检验的时间点、量表和决策规则；把它作为过程或质量指标，而不是把“检验显著”当作主要结果的因果证明。操纵检验失败时，区分三种情况：操纵确实无效、检验测量不可靠、或理论构念与指标不匹配；不要只因检验不显著就删除所有数据。

::: warning 常见误用
把 (alpha) 当作单维性证明、把“信度达标”当作效度证明、先删题再报告新系数，以及用操纵检验的 (p) 值筛选被试，都会夸大证据。任何删题、反向计分修正或异常处理都应记录规则，并进行敏感性分析。
:::
