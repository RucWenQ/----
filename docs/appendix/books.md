# A.1 推荐书单

::: tip 本节目标
读完本节后，你能按当前卡点挑一本“主干书”和一个官方在线入口，知道先读哪些章节、如何做读书笔记，以及何时把书中的例子换成自己的数据。书单不是购买清单；版本、语言、软件和课程要求不同时，以你实际使用的版本为准。
:::

## 不知道该买哪本？先按任务分流

一本书解决的是一类问题，不是整个科研流程。先写下你当前要交付的东西，再从表中选一条最短路线：

| 当前卡点 | 主干书/在线教材 | 先做的动作 | 不要期待它替你完成 |
| --- | --- | --- | --- |
| 题目太宽、论证没有主线 | Booth 等，《The Craft of Research》（4th ed.） | 先读“问题—主张—证据”相关章节，写一页论证地图 | 替你判断心理学构念是否测得有效 |
| 第一次学统计、想边做边练 | Navarro & Foxcroft，*Learning Statistics with jamovi*（在线教材） | 用自己的变量重做一个描述统计和区间练习 | 自动选择研究设计或修复偏差 |
| 写 APA 结构、表图和引用 | APA *Publication Manual*（7th ed.） | 只查本次投稿涉及的章节，保存页码/网址 | 覆盖目标期刊的特殊 author guidelines |
| 图表能运行但不可读 | Wickham、Navarro、Pedersen，*ggplot2*（3e，在线版） | 用数据映射—几何对象—主题—导出清单逐段改图 | 保证你的统计问题与图类型匹配 |
| 需要理解实验/准实验的因果边界 | Shadish、Cook、Campbell（2002） | 对照设计、干扰和外推限制画因果图 | 替代伦理审查或现实场域预试 |
| 开始做质性主题分析 | Braun & Clarke，*Thematic Analysis: A Practical Guide*（2022） | 先确定取向、编码单位和反思记录 | 把研究者解释变成“客观事实” |
| 要合并研究或做贝叶斯模型 | Borenstein 等（2021）或 McElreath（2020） | 先读数据结构、先验/异质性和诊断，再运行小例子 | 让不相容的测量或有偏样本变得可比 |

## 给新手的“三本主干”路线

如果还没有具体卡点，按下面顺序即可建立共同语言：

1. **问题与证据：** 用 Booth 等（2016）把一个兴趣改写成可检验问题，练习区分主张、证据、限制和缺口。
2. **数据与不确定性：** 用 *Learning Statistics with jamovi* 完成均值、分布、区间和简单模型的动手练习；遇到重复或嵌套观测，转到本手册的 [3 · 统计](../3-statistics/)。
3. **报告与交付：** 用 APA 7 手册查本次需要的表图、引用和统计报告，再用目标期刊最新模板覆盖冲突条款。

这三本不要求从第一页读到最后一页。每次读完一个概念，立刻在自己的研究备忘录中填“它改变了哪个决定、我还缺什么证据”。

## 手把手：把一本书变成可复用的研究笔记

以手机通知与学习正确率的教学示例为例，完成一次 30–60 分钟的读书循环：

1. **冻结问题。** 写“静音相对正常通知对即时正确率的平均比较”，并写下不讨论长期成绩。
2. **定位章节。** 在目录和索引中找问题、随机化/测量、估计与报告，而不是漫无目的通读。
3. **摘录可检查的命题。** 每条笔记只保留一句主张、适用条件、原文页码/小节和版本信息；不要把摘要当作自己的结论。
4. **换成自己的数据结构。** 标出谁是独立单位、是否有重复试次、结果变量如何计分；如果书中例子结构不同，记录差异。
5. **做一个最小练习。** 复现一个表、一个图或一个模型；代码和软件版本写进项目日志。无法运行时只记录步骤，不填写想象中的输出。
6. **写“下一步/求助点”。** 例如需要确认量表授权、功效假设或缺失机制时，链接到 [2 · 研究设计](../2-design/) 并请导师/统计顾问复核。

可直接复制的笔记模板：

| 字段 | 示例（教学示例） |
| --- | --- |
| 我的问题 | 静音通知是否改变即时正确率？ |
| 书中主张 | 随机化比较支持平均处理效应，但依从/干扰会改变解释 |
| 适用条件 | 处理分配和结果测量顺序明确；试次嵌套于被试 |
| 我采用的决定 | 主要结果固定为正确率，长期成绩列为不声称 |
| 原文定位 | 书名、版本、章节/页码或官方网址 |
| 待核查/求助 | 量表效度、缺失处理、目标期刊格式 |

## 如何处理版本、可得性和“看起来权威”的书？

- 记录完整书目信息：作者、年份、版次、出版社、ISBN/DOI 或官方网址；电子版和纸本若章节不同，注明版本。
- 软件书要记录软件版本和核查日期；菜单名称会变，优先看官方文档，再用书中概念解释为什么这样做。
- 先用图书馆、作者开放教材或出版社试读判断是否匹配，不要把价格、厚度或封面当作质量证据。
- 读到阈值、因果结论或“普遍适用”说法时，回到本手册对应方法页和原始研究；一本教材不能替你完成事实核查。
- 不上传受版权保护的整本书或含个人数据的练习文件到未经许可的 AI 服务；可以让 AI 帮你生成问题清单，再逐条回到原文核对。

## 常见疑问与排错

- **“我只会中文，先看哪本？”** 先用本手册和开放在线教材建立术语，再对照英文原文的目录/关键词；关键定义和引用仍记录原版信息。
- **“统计书里的例子和我的数据不一样？”** 先比较变量类型、观测单位、缺失和独立性；不要因为代码能运行就认为方法适用。
- **“同一主题有好几本书互相矛盾？”** 把差异写成条件（设计、估计目标、软件或版本），请导师决定课程/项目采用的口径，不要拼接成一个“平均定义”。
- **“书里说应该显著，结果不显著怎么办？”** 先报告估计和不确定性，检查功效、测量和模型诊断；不要改写结果去迎合书中示例。
- **“我需要读完整本才能开始吗？”** 不需要。围绕当前交付物读一个章节、做一个最小练习并留下定位，之后再扩展。
