# 7.2 IMRD 各部分要点

::: tip 本节目标
读完本节后，你能用同一条估计目标贯穿 Introduction、Methods、Results、Discussion（IMRD），把读者从“为什么做”带到“发现什么、能推到哪里”，并交付一份可复核的最小报告。
:::

## IMRD 解决的是什么阅读困难？

读者通常先问四件事：问题为什么重要（Introduction）、你具体怎么做（Methods）、数据给出了什么不确定的结果（Results）、这些结果改变了什么认识、又不能说明什么（Discussion）。IMRD 不是四个互不相干的作文盒子；每一节都应回应同一个估计目标，术语、样本和主要结果保持一致。

贯穿教学示例：随机分配本科生使用“静音”或“正常通知”，比较 25 分钟学习任务的正确率。以下文字只示范结构，不提供真实研究结果；若你使用自己的数据，所有数字须来自同一份分析脚本并标明软件版本。

## 最短决策路径

1. 先写一页分析备忘录：主要问题、估计目标、观测单位、主要结果和不声称的结论。
2. 用 Introduction 建立必要而不过度的证据链，最后一段给出可检验问题和方向（若有）。
3. 用 Methods 固定样本、设计、材料、程序、分析和偏离记录，使他人能复现。
4. 用 Results 按预先顺序报告描述、主要估计、不确定性和诊断；把探索性分析分开。
5. 用 Discussion 回答问题、解释边界、比较替代解释，提出下一步，而不是重复摘要。
6. 逐段检查“主张—证据—引用/表格”对应关系，并按期刊模板导出。

## Introduction：为什么现在要做这项研究？

### 四段式骨架

- **现象与后果：** 说明通知打断可能影响学习任务，并界定“即时正确率”而非长期成绩。
- **已知证据：** 综合实验与现场研究，比较样本、操纵、测量和精度；不要把相关证据写成因果证据。
- **缺口与替代解释：** 例如，通知内容期待可能与单纯注意力切换混淆；指出现有研究没有区分什么。
- **本研究承诺：** 明确人群、处理、主要结果、估计量和设计如何填补缺口；如有假设，写出方向和条件。

引言末段可以使用一段“本研究”模板：

> 我们在本科生短时学习任务中随机分配通知状态，估计静音相对正常通知的正确率平均处理效应。主要结果为任务正确率，试次嵌套于被试；我们预先规定任务难度交互为次要分析。该实验不能检验长期学习或所有手机使用情境。

## Methods：别人能按你的文字重做吗？

按执行顺序写，而不是按你写作时的思路写：

1. **参与者与取样：** 纳入/排除、招募来源、样本流失、伦理批准和知情同意；报告随机化单位。
2. **设计与材料：** 处理条件、随机序列、盲法（若有）、任务版本、通知内容/频率、设备和软件版本。
3. **程序与时间线：** 基线 → 分配 → 操纵检查 → 主要结果 → 随访；说明暂停、退出和偏离如何记录。
4. **变量与数据结构：** 说明每行代表被试还是试次、重复与嵌套关系、缺失编码和分析样本。
5. **分析计划：** 写模型、对比方向、效应量、95% CI/可信区间、诊断和敏感性分析；区分确认性与探索性。
6. **可复现材料：** 给出脚本、问卷/刺激、数据字典和版本化链接；不能公开时说明受限原因和获取路径。

## Results：先告诉读者数据回答了什么

建议按“样本与质量 → 主要估计 → 补充/敏感性 → 探索性”顺序：

- 先报告纳入、排除、流失和最终分析单位；流程图或表格应与正文数字一致。
- 给出各条件的描述性统计，再报告预先指定的组间差异或模型对比：估计值、95% CI（或可信区间）、效应量、样本量和模型诊断。仅给 *p* 值无法表达精度。
- 报告操纵检查和缺失处理，但不要把“注意到通知”当作主要结果的替代。
- 将未预注册的交互、子组或新指标标为探索性；不要用“趋势”掩盖区间跨过实际重要值的情况。
- 表格和图各承担一个任务：表格保留精确估计，图展示分布与不确定性；正文只解释读者需要的比较。

结果段落模板：

> 静音组相对正常通知组的正确率差异为 **[估计值]**（95% CI **[下限, 上限]**，效应量 **[名称与值]**，分析单位 *N* = **[ ]**）。区间包含 **[最小关注效应/零值]**，因此结果对“有多大改善”仍不确定。诊断显示 **[假设/敏感性分析]**；该估计不代表长期成绩变化。

## Discussion：结果改变了什么，没改变什么？

按四步收束：

1. **直接回答主要问题。** 用与 Results 相同的估计量和方向，避免引入新数字。
2. **放回证据地图。** 解释与哪些研究一致或不同，优先比较设计和测量，而非挑选支持自己的引用。
3. **列出限制与替代解释。** 例如短任务的生态效度、通知操纵是否被察觉、便利样本和缺失机制；说明它们如何影响外推。
4. **给出可执行下一步。** 复制到真实课程、延长随访或改进测量；不要把“需要更多研究”当作唯一建议。

因果措辞只在设计与诊断允许时使用。随机化支持处理与结果的平均比较，但不能自动消除不依从、干扰、测量无效或选择性流失。

## 交付前的 IMRD 对齐检查

| 检查 | 对照问题 |
| --- | --- |
| 术语 | Introduction 的“正确率”是否在 Methods 定义并在 Results 使用同一计分？ |
| 单位 | Methods 说明试次嵌套后，Results 是否错误地把试次数当样本量？ |
| 方向 | 估计值的“静音减正常”在表格、图和 Discussion 中是否一致？ |
| 不确定性 | 每个主要结论是否同时给出 CI/可信区间和诊断信息？ |
| 边界 | Discussion 是否明确短时实验不能推出长期或普遍因果？ |
| 追溯 | 每个关键主张能否回到数据、脚本、表号或引用？ |

## 常见疑问与排错

- **“引言应该写多少篇文献？”** 以论证需要为准；删掉不能支撑问题或设计的引用，避免按数量达标。
- **“Methods 还没决定分析怎么办？”** 先冻结估计目标和观测单位，再请统计顾问审阅；不要在 Results 里边看边选模型。
- **“CI 跨 0 就是没有效应吗？”** 只能说在该模型和样本下区间包含零，效应大小仍不确定；同时比较最小关注效应。
- **“发现一个有趣的子组能放主结果吗？”** 若未预先指定，单列探索性分析并说明多重比较和复制需求。
- **“期刊要求和 APA 不一样？”** 以目标期刊最新 author guidelines 为准；APA JARS 可作完整性清单，不能替代期刊格式。
- **“图表导出后字体变了？”** 固定字体、尺寸、色盲友好配色和导出格式；在提交 PDF/图片中逐页检查，不要只看编辑器预览。
