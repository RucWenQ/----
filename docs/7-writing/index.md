## 你会带着什么问题来？

“分析已经做完了，但读者看不出我回答了什么”“审稿意见很多，不知道先改哪条”“格式改了三遍仍然被退回”——本章把这些问题拆成一条可追踪的写作流程。重点不是套一个漂亮模板，而是让**问题、设计、结果、推断和交付文件彼此对齐**。

贯穿示例是“把本科生手机通知设为静音，是否改变 25 分钟学习任务的正确率”。它是结构练习，不提供真实研究结果；你自己的数字必须回到分析脚本、表格和版本记录。

::: tip 本章学习目标

- 把检索结果组织成“问题—证据—分歧—缺口—本研究”的综述，而不是论文清单；
- 用同一个估计目标贯穿 Introduction、Methods、Results、Discussion（IMRD）；
- 根据读者、方法和政策筛选期刊，准备可追踪的投稿包；
- 建立逐点回复矩阵，区分可以修改的文字、需要补充的分析和不能靠分析解决的设计边界；
- 按目标期刊要求导出盲审稿、表图和参考文献，并完成双向核对与最终质检。

:::

## 建议先准备什么？

先有一页研究备忘录：研究问题、估计目标、观测单位、主要结果、最小关注效应和“不声称什么”。这里的**估计目标**是“到底要比较或估计什么”，例如静音组与正常通知组的平均正确率差；**最小关注效应**是小到什么程度就不再值得作理论或实践解释，它不是把 _p_ < .05 换一个名字。如果这些字段还不稳定，先回到 [2.1 研究问题与假设](../2-design/question-hypothesis)、[2.2 测量](../2-design/measurement)、[2.4 取样与功效分析](../2-design/sampling-power) 和 [2.5 预注册与开放科学](../2-design/preregistration)。需要检查模型、效应量或不确定性时，回到 [3 · 统计](../3-statistics/)；需要统一图表和导出时，查看 [4 · 科研作图](../4-visualization/)。

## 一条从研究到提交的最短路径

1. **冻结估计目标。** 用一句话写清比较/关联/变化、原始量尺和分析单位；同时写下不能推出的结论。
2. **画证据地图。** 保存完整检索式和筛选理由，把每个关键主张连到原始研究、表号或页码。
3. **搭 IMRD 骨架。** 先填 Methods 的样本、设计、变量、缺失和分析，再写 Introduction 的动机与 Discussion 的边界。
4. **做一致性检查。** 抽查摘要、正文、表图、补充材料和脚本中的 *N*、方向、小数位、区间和术语。
5. **按期刊规则封装。** 在投稿当天重新读取 author guidelines，生成题名页/盲审稿/附件，保存核查日期和最终文件哈希或版本号。
6. **把反馈变成记录。** 对每条审稿意见写决定、证据、改动位置和未采纳理由；不能完成的事项向编辑或导师求助，不用猜测或编造结果填空。

## 贯穿示例：一个最小写作包长什么样？

手机通知示例的最小交付物不是一篇“看起来像论文”的文字，而是四个互相引用的文件：

1. **研究备忘录：** 静音相对正常通知的平均处理效应，结果为任务正确率，试次嵌套于被试；不推断长期学习。
2. **证据矩阵：** 每条背景主张对应研究设计、样本、估计和不确定性，并标记尚未核对的原文。
3. **分析与报告包：** 数据字典、脚本、表图和 IMRD 草稿；探索性分析单独标注。
4. **投稿记录：** 期刊政策快照、作者贡献/伦理/数据声明、cover letter、提交确认和稿件编号。

如果四个文件互相矛盾，先暂停润色，回到估计目标和数据结构检查；文字技巧不能修复设计或分析错误。

## 什么时候需要请别人介入？

当你无法判断主要观测单位、缺失机制、模型诊断或因果措辞，先找统计顾问或导师；当意见涉及作者资格、保密稿件、伦理批准、敏感数据或疑似研究诚信问题，找研究负责人、伦理部门或期刊编辑。AI 可以帮助列提纲、生成核对问题和发现格式不一致，但每个事实、引用、数字和软件版本都要回到授权来源与原始记录。
