# 7.3 投稿策略

::: tip 本节目标
读完本节后，你能根据研究问题、方法和开放政策筛出合适期刊，核对最新作者指南，准备 cover letter 与投稿文件，并保留一份可追踪的提交记录。
:::

## 选刊是在“押中率”，还是在找合适的读者？

投稿没有保证录用的窍门。更可靠的目标是让研究进入真正关心这个问题、接受这种方法，而且政策与你的伦理和开放承诺相容的期刊。影响因子、分区或 AI 推荐可以是线索，不能代替阅读期刊范围、近期文章和正式政策。

贯穿教学示例：你完成了一项随机实验，比较“手机静音”和“正常通知”对本科生 25 分钟学习任务正确率的影响。结果只支持短时任务中的组间比较，不能推到长期成绩。本节示范如何为这篇稿件选刊；期刊名、费用和处理时间不作虚构。

> **核查口径：** 投稿系统、费用、预印本和数据政策会变化。本页于 **2026-08-31** 核对方法入口；真正投稿时，以目标期刊官网当天的 author guidelines 和 submission checklist 为准。

## 最短决策路径

1. 用四句话冻结稿件身份：研究问题、设计与样本、主要估计、不能声称的结论。
2. 从关键文献、学会和可信数据库找 4–6 本候选刊，不直接采用邮件邀稿或 AI 给出的名单。
3. 对每本刊阅读 aims & scope、文章类型和近两年 3–5 篇相关文章，判断读者与方法是否匹配。
4. 核对同行评审、开放获取费用、预印本、数据/代码、伦理、篇幅和文件要求；来源和日期写进选刊表。
5. 用“主题匹配—方法匹配—政策可行—成本可承受”排序，与全体作者确认第一选择和备选顺序。
6. 只按第一选择准备格式、cover letter 和提交包；逐项对照官网清单，不凭印象填写系统。
7. 提交后保存最终文件、确认邮件、稿件编号和披露内容；状态变化只按系统或编辑来信解释。

## 什么样的期刊值得进入候选名单？

先建一张表。空白格意味着“尚未核对”，不意味着“默认符合”。

| 要核对的维度 | 去哪里看 | 对示例稿要问什么 | 危险信号 |
| --- | --- | --- | --- |
| 读者与范围 | Aims & Scope、近期目录 | 是否持续发表注意、学习或数字行为实验？ | 只凭期刊名猜范围 |
| 文章类型与方法 | Author Guidelines、近期同类论文 | 接受单项实验吗？是否要求注册报告或特定清单？ | 方法或篇幅明显不符仍硬投 |
| 编辑与评审 | 官网编辑部、同行评审说明 | 编辑与评审流程是否透明？ | 冒用学者姓名、承诺异常快速录用 |
| 费用与许可 | 官网费用和开放获取页 | APC、彩图或超页费用由谁承担？许可是否可接受？ | 费用到录用后才突然出现 |
| 开放与伦理政策 | 数据、代码、预印本、伦理、利益冲突页 | 去标识数据能否共享？不能共享时允许怎样说明？ | 要求隐藏伦理问题或虚假引用 |
| 可发现与保存 | ISSN、可信数据库、长期保存说明 | 正式版本能否稳定检索和保存？ | 网站信息互相矛盾、联系方式含糊 |
| 时间信息 | 期刊公开统计或编辑部说明 | 是否有可追溯的公开数据？ | 第三方给出无来源的“平均天数” |

使用 [Think. Check. Submit.](https://thinkchecksubmit.org/journals/) 的问题清单检查期刊身份，但不要把任何单一名单当作永久黑白名单。遇到新刊、相似刊名、私人邮件邀稿或无法确认的费用时，请图书馆员、导师或科研管理人员一起核对。

## 手把手：做出一张能解释的选刊表

1. **写稿件卡片。** 记录题目草案、150 字摘要、文章类型、设计、观测单位、主要结果、材料/数据可用性和目标读者。示例稿的核心是“短时随机实验的平均组间差异”，不是泛泛的“手机危害”。
2. **生成候选池。** 查看最相关论文发表在哪里、领域学会维护哪些期刊，并在可信数据库检索同类题名和关键词。AI 可帮你扩展关键词，但每一本刊都要回到官网核对。
3. **做全文匹配。** 每刊精读 3–5 篇近期同类文章的摘要、方法和讨论。记录“为什么匹配”与“为什么可能不匹配”，不要只记刊名和指标。
4. **抄录政策，不要凭记忆概括。** 把文章类型、字数计算方式、匿名要求、报告清单、材料共享、预印本、费用和文件格式连同网址、核查日期写入表格。
5. **排除不可能项。** 若期刊不收该文章类型、读者明显不匹配、费用无法承担，或政策与知情同意承诺冲突，就移出候选池。
6. **让共同作者确认。** 选刊涉及受众、成本和署名责任。把表格发给所有作者，明确第一选择、备选顺序以及谁负责系统提交。
7. **保存决策快照。** 将选刊表和网页快照放入项目的 `submission/01-journal-selection/` 目录；以后改投时更新日期，不覆盖旧版本。

预期结果不是“找到必收的期刊”，而是一份任何合作者都能回答“为什么投这里、政策在哪里查到、若拒稿下一站是什么”的记录。

## Cover letter 要替编辑解决什么问题？

Cover letter 的任务是帮助编辑快速判断“稿件是什么、为何适合本刊、是否满足基本声明”，不是重复摘要或夸大结论。期刊若提供模板，优先使用模板。

::: details Cover letter 最小骨架（教学模板）
> Dear [Editor’s name / Editor],
>
> Please consider our manuscript, “[title],” as a [verified article type] in [journal]. We estimate [primary estimand] in [population and design]. The manuscript’s main contribution is [one bounded contribution], which is relevant to the journal’s readers because [specific fit with scope or recent conversation].
>
> This work is original, is not under consideration elsewhere, and has been approved by all authors. [Ethics approval/consent statement as applicable.] [Conflict-of-interest and funding statement.] [Preprint, data, materials, and code status according to the journal’s policy.]
>
> Thank you for your consideration.
>
> Sincerely, [corresponding author]
:::

逐句核对以下边界：

- “首次”“证明”“彻底解决”需要非常强的证据；示例稿只能说明预定人群与短时任务中的估计。
- 不要声称读过编辑的工作来套近乎，也不要建议存在利益冲突的审稿人。
- “未一稿多投”、作者同意、伦理、利益冲突、资金和预印本状态必须真实；不适用时按期刊要求写明，不要复制虚假模板。
- 推荐或回避审稿人时给出可核查理由，让编辑决定，不用私人关系影响评审。

## 提交包里应该有什么？

不同期刊要求不同，但至少建立一份本地清单：

- **主文稿：** 题名、摘要、关键词、正文、参考文献，以及期刊要求的表图位置；盲审稿不含可识别信息。
- **独立题名页：** 作者姓名、单位、ORCID、通讯信息、作者贡献、资金和利益冲突（若期刊要求分开）。作者贡献可按 [CRediT](https://credit.niso.org/) 角色讨论，但角色不能替代作者资格标准。
- **表、图和补充材料：** 文件名、编号、正文引用和上传顺序一致；分辨率、字体与可访问性见 [7.5 排版与格式](./formatting)。
- **透明性材料：** 伦理批准、同意、预注册、数据/代码可用性、报告清单和偏离说明。不能公开参与者数据时，说明限制和合规访问路径。
- **Cover letter 与系统字段：** 题名、摘要、作者顺序、声明和推荐审稿人要与最终文稿一致。

提交前请一位没有参与排版的合作者做“交叉检查”：从系统页面反查主文稿，再从主文稿反查附件。任何作者顺序、主要结果或公开承诺不一致，都应先停下修正。

## 提交后怎样记录，而不是猜进度？

1. 保存系统生成的 PDF，并逐页查看公式、匿名信息、表图和补充材料是否完整。
2. 记录提交日期、稿件编号、提交版本的文件校验名、通讯作者和所有声明。
3. 状态名称由各系统自定义；“with editor”“under review”不能可靠换算成剩余天数。
4. 只有超过期刊公开时限或长时间无更新时，才由通讯作者发送简短、礼貌、带稿件编号的询问信。
5. 若发现影响结论的错误，立即与全体作者和编辑沟通，不要等待评审“是否会发现”。

## 常见疑问与排错

- **“先投高一点试试，反正没损失？”** 有机会成本：格式转换、编辑等待和共同作者时间。若范围不匹配，先移出；若只是竞争激烈但读者匹配，可由作者团队权衡。
- **“收到保证录用的邀稿邮件？”** 不点击邮件中的付款链接；从独立渠道访问期刊官网，核对编辑、ISSN、费用、评审与保存信息。
- **“AI 推荐了一本很合适的期刊？”** 把它当候选词条。核对期刊是否真实、是否仍出版、范围和政策是否匹配，不能引用 AI 的描述作证据。
- **“没有钱支付 APC？”** 开放获取不等于一定收费。查订阅发表选项、机构协议和减免政策，并在提交前确认；不要等录用后才讨论。
- **“共同作者不同意第一选择？”** 回到选刊表比较受众、政策、成本和时间证据；若涉及署名、伦理或利益冲突，不要由通讯作者单独决定。
