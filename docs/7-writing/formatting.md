# 7.5 排版与格式细节

::: tip 本节目标
读完本节后，你能把目标期刊的最新要求整理成格式矩阵，统一标题、正文、统计符号、表图和参考文献，导出并检查盲审稿与附件，而不是靠提交前逐页救火。
:::

## APA 7 和期刊模板冲突时听谁的？

先遵循目标期刊当前的 author guidelines、文章类型说明和投稿系统清单；这些文件没有规定的部分，再用 APA 第 7 版补齐。实验室旧模板、学长论文或 AI 生成的“APA 规则”只能作线索，因为它们可能针对旧版手册或另一家期刊。

贯穿教学示例仍是手机通知实验。你需要交付盲审主文稿、独立题名页、两张图、一个表、补充方法与数据可用性声明。本节不虚构具体期刊的字号、字数或图片分辨率；真正数值必须从所投期刊官网逐项抄录，并标注核查日期。

> **版本口径：** 本页于 **2026-08-31** 核对 APA Style 与 JARS 入口，主干为 *Publication Manual of the American Psychological Association* 第 7 版（2020），尤其是第 2、3、6–10 和 12 章。期刊规则会更新，提交当天再查一次。

## 最短决策路径

1. 下载并保存目标期刊的 author guidelines、文章类型页、模板和提交清单，记录网址与日期。
2. 把要求抄成矩阵：主文稿、题名页、摘要、匿名、参考文献、表图、补充材料、数据/代码和文件格式。
3. 在 Word 样式、LaTeX 类文件或 Quarto/R Markdown 模板中统一控制格式；不要逐段手调同一种标题。
4. 用文献管理器刷新引文，再做“正文到文末、文末到正文”的双向核对和 DOI 元数据核查。
5. 独立检查每个表图：正文引用、编号、标题/图注、统计信息、可读性、文件规格和导出结果。
6. 生成盲审稿、题名页和附件；搜索作者、机构、伦理单位、文件属性及致谢中的身份线索。
7. 导出系统要求的 PDF/Word/图片，逐页查看；最后核对投稿系统字段与本地最终版一致。

## 先做一张格式矩阵

| 对象 | 要从官网抄什么 | 本地怎么检查 | 常见遗漏 |
| --- | --- | --- | --- |
| 文章类型 | 字数、摘要结构、关键词、章节顺序 | 字数统计与标题列表 | 用了另一文章类型的上限 |
| 主文稿 | 匿名方式、行距、页码、行号、文件类型 | 导出 PDF 后搜索身份词 | 文件属性或自引暴露身份 |
| 题名页 | 作者、单位、ORCID、通讯、贡献、声明 | 与投稿系统逐字段比对 | 作者顺序或单位不一致 |
| 参考文献 | 引用体例、DOI/URL、文献数量限制 | 文献管理器刷新 + 双向核对 | 正文有引文、文末无条目 |
| 表与图 | 是否嵌入、单独上传、尺寸、格式、分辨率 | 按最终尺寸打开并打印/缩放 | 图中文字在缩小后不可读 |
| 补充材料 | 命名、匿名、引用方式、允许格式 | 主文稿链接到每个附件 | 附件版本与正文数字不同 |
| 开放与伦理 | 数据、代码、预注册、资金、冲突、伦理声明 | 与批准文件和仓库核对 | 复制了不适用的模板声明 |

矩阵中的每个数值都要带来源。期刊网页、PDF 模板和投稿系统若互相冲突，先截图保存，再向编辑部询问，不要自行选择最宽松的版本。

## 手把手：从内容稿变成提交稿

1. **冻结内容版本。** 在开始排版前确认主要文字、表图和参考文献已基本稳定；保留可回退的版本号。
2. **建立样式层级。** 只用“标题 1/2/3、正文、引文、表注”等命名样式。修改字体或段距时改样式定义，不逐段点格式。
3. **统一结构与术语。** 对照 [7.2 IMRD](./imrd) 检查题名、摘要、方法、结果和讨论使用同一个样本、结果变量和估计方向。
4. **刷新引文。** 先在 Zotero 等工具中修正作者、年份、题名、期刊、卷期页和 DOI，再刷新文稿。不要直接在生成后的参考文献里手改后忘记同步数据库。
5. **重建表图清单。** 列出 Table 1、Figure 1、Figure 2 和 Supplement S1；逐项确认正文按首次出现顺序引用，附件名和图注一致。
6. **处理匿名。** 按期刊政策把作者信息移到题名页；必要时把自引改成中性表达，但不能删掉理解研究所需的文献。
7. **生成最终格式。** 按要求导出 DOCX/PDF/TIFF/EPS 等文件；图片格式和分辨率只使用目标期刊给出的数值。
8. **做视觉检查。** 在最终尺寸查看分页、孤行、公式、上下标、特殊字符、表格跨页、图中文字和链接；不能只信编辑器预览。
9. **做内容校验。** 抽查每个主要数字能回到分析输出；核对摘要、正文、表图和补充材料的样本量、方向、单位与小数位。
10. **封存提交包。** 保存最终文件、格式矩阵、网页核查日期和投稿系统生成的 PDF，提交后避免继续覆盖同名文件。

## 表格怎样做到“离开正文也能读懂”？

一个表格应回答一个明确问题，而不是把全部软件输出贴进去。

- **编号与标题：** 按正文首次引用顺序编号，标题说明表中是什么，不在标题里解释所有结果。
- **列名与单位：** 变量名、组别、时间点和单位明确；小数位在同类列中一致，但不要为了整齐伪造精度。
- **估计与不确定性：** 优先保留估计值、标准误或区间、效应量和样本/观测单位；只给星号不能让读者判断大小与精度。
- **表注：** 一般注释解释缩写、数据结构和整体说明；特定注释对应某个单元格；概率注释说明符号与 *p* 值。只使用实际需要的注释。
- **可复核：** 表中的样本量、模型名称和对比方向必须能回到脚本或输出；四舍五入后若合计略有差异，在注中说明。

示例表不能把 2,000 个试次写成 *N* = 2,000 而不说明它们嵌套于 80 名参与者。标题、表注或方法中应清楚区分参与者数与观测数。

## 图怎样兼顾统计问题和投稿规格？

先决定图要展示原始分布、模型估计还是诊断，再决定几何对象。具体的数据映射、统计变换和导出流程见 [4.5 投稿级图的细节](../4-visualization/publication-quality)。排版阶段还要手动检查：

- 图例、颜色、线型和符号能否让读者区分组别；灰度打印和常见色觉差异下仍可辨认。
- 字体、字号、坐标刻度和注释在期刊最终栏宽下是否可读，而不只是全屏时清楚。
- 误差线究竟是 SD、SE、CI 还是可信区间；图注写清估计对象、区间和分析单位。
- 分面顺序、坐标范围和截断是否可能夸大差异；若截断坐标有必要，要让读者看得出来。
- 图片文件的尺寸、色彩模式、格式和分辨率是否来自该期刊当前要求。
- 图注或投稿系统要求的替代文本是否描述图的目的、主要模式和必要结构，而不是只写“见图 1”。

如果手动拖动了标签、图例或注释，保存可复现代码或操作记录；修改后重新导出，不在最终图片上做无法追踪的“最后一点修图”。

## 参考文献最容易错在哪里？

1. **元数据错。** 从原文、出版社或 Crossref 核对作者顺序、年份、题名、期刊、卷期页和 DOI；不要把搜索摘要当书目信息。
2. **正文与文末失配。** 正文每条引文都应有文末条目，文末每条也应在正文出现；软件自动生成不等于自动正确。
3. **版本不清。** 预印本、在线优先版、更正和正式版本可能并存。引用你实际阅读和支持主张的版本，并核对是否有更正或撤稿。
4. **DOI 写法混乱。** 按 APA 7 和期刊要求使用 `https://doi.org/...`；没有 DOI 时不要猜一个。
5. **二手引用冒充原文。** 没有读到原文就不要写成亲自核对；必要时明确二手引用并继续寻找原始来源。
6. **AI 编造条目。** AI 可帮助检查格式模式，不能作为文献存在或内容的证据；每条引用回到真实来源。

## 盲审稿真的匿名了吗？

按期刊的具体匿名政策检查，而不是盲目删除全部自引：

- 题名页是否与主文稿分离；页眉、致谢、作者贡献、资金和通讯信息是否移除。
- 文件名、文档属性、批注、修订记录和图片元数据是否含姓名或机构。
- 伦理批准单位、数据仓库链接、预注册和自引是否直接识别作者；若无法匿名，按期刊允许的占位方式处理。
- 补充材料、代码 README 和问卷页脚是否仍有实验室名称。
- 匿名不能以删掉关键方法、利益冲突或必要引用为代价；拿不准时询问编辑部。

## 提交前的 15 分钟质检

- [ ] 题名、摘要、正文和投稿系统中的研究对象与主要结论一致。
- [ ] 样本流、主要估计、区间和效应方向在正文、表图、补充材料中一致。
- [ ] 每个缩写首次出现时解释；变量名和量纲前后一致。
- [ ] 所有表图都在正文引用，编号连续，图注能独立理解。
- [ ] 所有正文引文与参考文献双向匹配，DOI 没有猜测项。
- [ ] 盲审稿、题名页、cover letter 和补充材料的版本与命名正确。
- [ ] 导出 PDF 中没有空白页、截断表格、乱码、失效公式或不可读图字。
- [ ] 数据、代码、预注册、伦理、资金和利益冲突声明真实且互相一致。

## 常见疑问与排错

- **“APA 7 到底允许哪种字体？”** APA 为学生稿和专业稿提供多种可读字体选择；期刊可能另有模板。不要把某一种字体当作跨期刊的唯一规则。
- **“能用期刊已发表 PDF 模仿格式吗？”** 已发表版经过出版社排版，不等于作者投稿格式。以 author guidelines 和模板为准。
- **“Zotero 套了期刊样式就完成了吗？”** 没有。仍要核对元数据、缺失字段、正文—文末对应和该刊的特殊要求。
- **“表图放正文还是另传？”** 查期刊当前说明；两种做法都存在。不要同时上传两个不一致版本。
- **“系统生成的 PDF 与本地不同？”** 暂停提交，定位字体嵌入、公式、分页或图片转换问题；只有系统 PDF 复核无误后再确认。
