# 6.3 从模糊到可执行

::: tip 本节目标
读完本节后，你能把“我想研究 X”拆成构念定义、可观察指标、操作程序、数据结构和分析计划，并指出哪些推论仍需要额外证据。
:::

## 先写估计目标，再挑测量

**操作化**不是给抽象名词找一个问卷就结束，而是规定“对谁、在什么条件、测什么、何时测、用什么单位比较”。先写估计目标，再选择指标，能避免测量与问题错位。

贯穿示例：把“通知影响专注”改成“在随机分配静音/正常通知的本科生中，25 分钟任务的平均正确率差异”。构念是“任务中的持续专注”，主要结果是正确率；通知状态是处理变量，真正的观测单位是被试，而不是每道题（题目是被试内重复观测）。

## 一张映射表解决大多数含糊

| 层次 | 示例写法 | 需要留下的证据 |
| --- | --- | --- |
| 构念（概念定义） | 持续专注：在目标任务期间维持目标导向反应 | 理论来源、与相近构念的区别 |
| 指标（操作定义） | 25 分钟任务正确率；次要指标为漏答率和主观投入 | 计分公式、量尺、缺失规则、天花板检查 |
| 操作（处理/测量程序） | 随机分配静音或正常通知；统一通知频率和内容 | 脚本版本、设备权限、操纵检查 |
| 数据结构 | 每人一行汇总结果；若保留试次，则试次嵌套于人 | ID、时间、条件、重复次数、独立单位 |
| 分析与报告 | 组间均值差及 95% CI；试次数据用混合模型 | 模型、效应量、诊断、外推边界 |

## 六步操作流程

1. **写概念边界。** 用一两句说明构念包含和不包含什么；“专注”不自动等于“喜欢任务”或“反应快”。
2. **指定观测指标。** 选择主要结果和次要结果，写单位、方向、计分和最小关注效应；若用量表，记录版本、翻译和授权。
3. **画出时间顺序。** 标记基线、操纵、操纵检查、主要结果和随访。结果发生在操纵前，就不能按该设计声称因果。
4. **固定实施细节。** 写招募、随机化、说明语、设备、时长、暂停/退出、缺失和排除；把脚本与代码版本化。
5. **先做测量与流程预试。** 检查理解率、反应分布、缺失、权限和天花板/地板；预试只用于改流程，除非方案明确把它作为正式样本。
6. **把指标接到分析。** 预先写模型、效应量、不确定性、诊断和替代方案。多个指标不要事后挑最好看的一个；把探索性结果标清。

::: details 示例：最小可执行方案

- 参与者：符合纳入标准的本科生；随机化单位为人。
- 处理：静音 vs 正常通知，各 25 分钟；脚本固定 10 次标准化通知。
- 主要结果：任务正确率（0–1），目标比较为静音减正常的均值差；报告 95% CI。
- 次要结果：漏答率和任务后投入评分；仅作补充，不替代主要结果。
- 操纵检查：任务后报告是否注意到通知；检查失败者不自动删除，做预先规定的敏感性分析。
- 边界：短时实验不能证明长期学习成绩变化；若非随机招募，也不能外推到所有本科生。

:::

## 如何检查“测到了想测的东西”？

至少记录三类证据：**内容**（指标覆盖构念的哪些面向）、**关系**（与相近/不同构念的关联是否符合预测）、**过程**（被试是否按预期理解和执行）。效度不是量表的永久标签，而是针对特定解释和人群的证据；同一指标换人群、语言或时间点后要重新检查（Borsboom et al., 2004）。

对量表或行为指标，不要把一次高信度当作“有效”的证明。记录内部一致性或测量误差、缺失模式、操纵检查和测量不变性需求；如果关键证据缺失，用“指标与构念的关联”而不是“成功测量了构念”来写结果。可对照 [2.2 测量](../2-design/measurement) 的信度、效度与操纵检查流程。

## 常见错位与修复

- **构念—指标错位：** 用反应时代表“学习效果”却没有准确率或迁移任务。修复：把“即时任务表现”和“长期学习”分成两个结果。
- **分析单位错位：** 把 40 道题当 40 个独立样本。修复：按被试汇总，或使用能表示试次嵌套的模型。
- **操纵检查当结果：** “被试注意到通知”只能说明操纵是否被感知，不能代替专注结果。
- **事后改口：** 先看到哪个指标显著，再把它命名为主要结果。修复：在 [2.5 预注册与开放科学](../2-design/preregistration) 中锁定主要结果并记录偏离。
- **把测量有效写成因果有效：** 好指标不能弥补无随机化、时间顺序错误或严重干扰；因果边界仍由设计决定。

## 何时需要求助？

如果构念涉及临床诊断、未成年人、高风险操纵、跨语言比较、复杂重复测量或隐私敏感数据，先咨询导师、伦理审查和测量/统计专家。无法确认量表授权、评分规则或软件版本时，保留 `::: info 待核查` 记录，不凭记忆补齐细节。
