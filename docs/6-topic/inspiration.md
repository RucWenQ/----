# 6.1 灵感的来源

::: tip 本节目标
读完本节后，你能把一个模糊的“我对某现象感兴趣”记录成可追踪的线索，做一次小型文献地图，并产出 2–3 个可供评估的研究问题。
:::

## 你不是在等“天才想法”

研究灵感通常来自三种材料的交叉：**已有证据的缝隙**、日常或实践中的反常观察、以及理论预测之间的冲突。所谓“新颖”不等于从未有人提过，而是你能说明新增了什么人群、情境、测量、时间尺度或竞争解释。先把线索写下来，再用文献和可行性检查筛选；不要先决定结论，再倒找支持它的论文。

贯穿示例：你观察到同学学习时频繁查看手机通知，想问“通知会不会损害专注”。这句话还没有指定人群、比较条件、结果指标或时间点，只能算观察，不是研究问题。

## 三条入口，如何变成问题？

| 入口 | 先问什么 | 常见产出 | 需要防的坑 |
| --- | --- | --- | --- |
| 文献缝隙 | 不同研究的样本、操纵或结果为何不一致？ | 复制、边界条件、竞争模型 | 把“没人研究”误当重要 |
| 现实观察 | 谁在什么情境下遇到可重复的现象？ | 描述、预测或干预问题 | 用个案印象代替基线数据 |
| 理论冲突 | 理论 A 与 B 对同一条件给出什么不同预测？ | 直接比较或区分机制 | 只比较术语，不比较可观测结果 |

## 从线索到候选问题：五步工作流

1. **建一张线索卡。** 写下日期、来源、现象、你看到的反常点和可能的观测单位（人、试次、群体或文本）。把原始链接或 DOI 一并保存。
2. **做小型文献地图。** 用 3–5 个同义关键词检索，先读综述和近年相关论文，再追关键原始研究。记录数据库、日期、完整检索式和纳入/排除理由；对关键论文做一次后向（参考文献）和前向（被引文献）追踪。表格至少含样本、情境、主要变量、结果方向和局限；高被引不等于结论一定可靠，也不要只抄摘要。
3. **列出替代解释。** 对“通知影响专注”同时写出注意力切换、任务难度、通知内容期待和自我选择等解释，并记录每种解释需要什么测量或对照。
4. **生成三个版本。** 让问题分别偏向描述、关联/预测和因果；每个版本都写清人群、X、Y、比较、时间和估计目标。例如：“在本科生中，静音 25 分钟与正常通知相比，任务正确率的平均差异是多少？”
5. **做一次反向检查。** 如果删掉“为什么”，问题仍能由数据回答吗？若不能，先补上可观测指标。因果版本至少要有先于结果的处理、实际执行的随机分配（或其他可辩护的识别设计）、预先规定的比较和对缺失/干扰的处理；做不到时，把措辞改为“关联/预测”，或换设计。

::: details 示例：把同一观察改写三次

- **描述：** 本科生在 25 分钟学习任务中平均查看几次通知？
- **关联：** 通知查看次数与任务正确率如何相关？记录任务前的自我控制和基线能力。
- **因果：** 随机分配“静音”或“正常通知”，比较任务结束时正确率的平均处理效应；预先规定通知内容、时长和排除规则。

三种问题都可能有价值，但它们的样本量、伦理风险和统计模型不同。不要用关联设计回答因果问题。

:::

## 如何判断线索值得继续？

给每个候选问题写一页备忘录：研究对象与情境、主要比较、最小关注效应、现有证据、替代解释、可获得的数据、伦理风险和你**不打算**声称的结论。再把它交给同门或导师做“复述测试”：对方能否用自己的话说出 X、Y 和比较？如果不能，先回到第 4 步。

线索阶段不需要马上写完整假设，但要保留搜索式、日期和排除理由。这样以后发现相似研究时，可以区分“重复验证”“边界扩展”和“真正的新问题”，也能避免把事后灵感伪装成事前计划。

## 常见疑问与排错

- **“文献已经很多，还能做吗？”** 可以。换人群、情境、测量或直接复制并提高精度，都可能是合理贡献；先说明增量而不是强行宣称首创。
- **“只有一个生活案例怎么办？”** 把它当假设来源，先找基线或先做小规模描述，不把个案频率当总体比例。
- **“关键词搜不到结果？”** 列出构念的同义词、旧术语和测量名称；用引文追踪补回关键词的盲区，并记录检索范围。
- **“想法很多，先做哪个？”** 把候选问题带到 [6.2 评估题目的好坏](./evaluation) 做四象限评分，而不是凭兴奋程度决定。
