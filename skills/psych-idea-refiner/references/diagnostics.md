# 结构化诊断清单（Diagnostics）

**何时用**：用户卡住、明确要诊断、或某块光靠追问推不动时（见 SKILL.md「卡住了怎么办」）。
**怎么用**：打开对应那一节，**逐条对照当前 idea**——满足 ✓ / 缺 ✗ / 有风险 ⚠，每条给一句**具体到这个 idea** 的判断，不要照抄清单。给完诊断**立刻回到追问**，把选择权还给用户："这几个点里你想先处理哪个？"

诊断是为了让对话动起来，不是给标准答案。给方向时给 2–3 个候选让用户选。

---

## 构念与测量

- [ ] **定义清晰**：核心构念有一句能写进 method 的操作型定义，不是只有一个名词。
- [ ] **区分效度**：跟最邻近的构念划清了界（说得出"它不是 X，因为……"）。
- [ ] **测量选择**：测量方式（量表/行为/反应时/生理/任务/评定）跟构念的性质匹配——内隐的东西别硬用自陈测。
- [ ] **信效度**：用成熟工具（有信效度证据）还是自编（要先验证）？心里有数。
- [ ] **操纵有效性**（若有操纵 IV）：有操纵检验；操纵没有顺带改别的东西。
- [ ] **方法同源风险**：不是所有变量都用同一种方法测（否则 common method bias）。
- [ ] **jingle-jangle**：构念名没跟别的东西撞名；没在给已有构念重新起名。

**常见病**：构念漂浮（说得热闹测不出来）；用一个总分量表测一个其实多维的东西；操纵同时改了好几个变量说不清是哪个起作用。

## 变量与因果结构

- [ ] **角色明确**：IV/DV/中介/调节/混淆每个变量都归了位，没有悬空的变量。
- [ ] **主张与设计匹配**：声称因果就有支持因果的设计（操纵+随机分配或强因果推断设计）；只有相关设计就别用因果语言。
- [ ] **反向因果**：考虑过 Y→X 的可能并能排除/承认。
- [ ] **第三变量**：点得出最可能的混淆，并有控制或排除的办法。
- [ ] **中介质量**：中介有理论机制，不是事后硬塞；最好能实验操纵中介（experimental-causal-chain），而非纯统计中介。
- [ ] **调节定位**：调节变量是理论预测的边界条件，还是探索性的（探索性要诚实标注）。

**常见病**：相关数据写因果结论；统计中介当因果机制用（X→M→Y 三个都是测量值，回归显著就宣称机制）；混淆变量只字未提。

## 方法与设计

先按**问题类型**定大类，别让方法绑架问题：

| 问题类型 | 典型设计 |
|---|---|
| 在发生什么（描述） | 调查、观察、内容分析、描述性研究 |
| X 和 Y 有没有关系（相关） | 相关/回归设计、横断调查 |
| X 是否引起 Y（因果） | 随机实验；满足识别假设的准实验/自然实验；纵向设计只能补充时间顺序证据 |
| 怎么引起的（机制） | 中介设计、实验操纵中介、过程追踪 |
| 人怎么经历 X（体验） | 质性访谈、扎根理论、叙事、现象学 |

再过设计细节：
- [ ] **设计-问题对齐**：现有设计真能回答这个问题。
- [ ] **被试内/间权衡**：选择有理由（被试内省样本但有顺序效应；被试间干净但要更多人）。
- [ ] **效度适用性**：内部效度与研究情境的现实适用性分别评估；两者不必机械地视为零和取舍。
- [ ] **样本与总体**：目标总体明确；推广范围跟样本匹配（WEIRD 样本别推广到全人类）。
- [ ] **可行性**：数据真能在合理时间/成本内拿到；有 plan B。

**常见病**：想要因果却只做了相关；生态效度为零的实验硬说能解释真实行为；样本能拿到的和结论想推广的对不上。

## 可证伪性（轻量，但每个假设都该过）

- [ ] 说得出"什么结果会**推翻**这个假设"。
- [ ] 想得到至少一个**竞争假设**（最显然的替代解释），并且设计能把它和你的假设区分开。
- [ ] 假设不是"怎么着都对"——无论数据朝哪边走都能自圆其说的假设，等于没假设。

## 开放科学（收尾轻过，不深挖）

- [ ] **可预注册性**：假设、设计、分析能不能事先写定？关键的预注册要点（主假设、排除标准、主分析）是什么？
- [ ] **效应量预期**：对效应大概什么量级有没有预期？（关系到样本量）
- [ ] **功效/样本量**：样本量是拍脑袋还是有功效分析支撑？
- [ ] **测量稳健性**：关键测量稳不稳，要不要预先定好信度门槛。

用户说"这块先不管"就记"待定"放过。

## 伦理（收尾轻过，不深挖）

- [ ] **知情同意 / 欺骗**：有欺骗范式吗？事后 debriefing 怎么做？
- [ ] **易受伤害人群**：涉及未成年人、临床人群、弱势群体吗？
- [ ] **风险**：研究过程会不会伤害被试（含心理不适）？
- [ ] **误用**：结论被误用的最坏情况是什么？

## FINER 自评表（spec 收尾用）

对最终的研究问题，每维打 1–5 分配一句理由。这是**体检**，不是打分排名——低分的维度正是 spec 里该标注的风险点。

| 维度 | 含义 | 1 分（弱） | 5 分（强） |
|---|---|---|---|
| **F**easible 可行 | 现有方法/数据/资源答得了吗 | 答不了 | 用明确方法+拿得到的数据能答 |
| **I**nteresting 有趣 | 有人在乎答案吗 | 琐碎或早有定论 | 切中一个真困惑或矛盾 |
| **N**ovel 新颖 | 提供了新东西吗 | 完全重复已有工作 | 新视角/新方法/新证据 |
| **E**thical 合伦理 | 有伦理问题吗 | 有重大伦理顾虑 | 无伦理问题，收益大于风险 |
| **R**elevant 相关 | 有理论或实践意义吗 | 无意义 | 直接影响理论/实践/政策 |

FINER 用于暴露薄弱环节，不设机械的平均分或淘汰门槛。Novel 未经足够检索时应标为“未评估”，而不是凭直觉评分。
