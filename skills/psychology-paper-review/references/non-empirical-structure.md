# 非实证论文（Theory / Opinion / Narrative Review / Commentary）总结模板

非实证论文的内容组织高度依赖论文本身的章节结构，所以这里**没有固定的总结模板**——核心原则是"按原文章节顺序梳理"，但要做以下加工。

## 总体策略

1. **保留原文的章节顺序**——不要重排。作者的论证顺序本身就是信息。
2. **用原文章节标题作为你的二级标题**（必要时翻译成中文，原英文用括号附后）。
3. **每个章节做"压缩 + 转述"，不做"重写"**——目标是 1/4 ~ 1/3 长度的中文版。
4. **保留作者的核心论点和关键证据**，砍掉细节性举例（除非这个例子是论证的关键）。

## 各类型的差异化处理

### Opinion / Perspective

通常结构：现象引入 → 现有解释及其不足 → 作者主张的新观点 → 论据 → 含义 / 呼吁。

写法重点：
- **作者的核心主张（thesis）必须明确呈现**，最好放在文献总结的开头单独一段。
- 论据按原文顺序逐个梳理，每个论据用 1–3 句概括。
- 如果作者反对某个流行观点，明确写出"作者反对 X 观点，认为 Y"。

### 理论综述（Theoretical / Conceptual Review）

通常结构：领域背景 → 已有理论 → 新框架（作者提出的）→ 框架要素 → 应用前景。

写法重点：
- **新框架的结构要画出来**——用文字 + 嵌套列表呈现。如果原文有概念图（conceptual model），考虑画 HTML 示意图。
- 框架的每个要素用 2–4 句解释（定义 + 与其他要素的关系）。
- 如果作者引用了大量前人研究来支撑新框架，挑 3–5 项最关键的提；不必穷举。

### 叙事性综述（Narrative Review）

通常结构：领域引入 → 主题 1 + 相关研究 → 主题 2 + 相关研究 → ... → 整合 / 未来方向。

写法重点：
- 按原文主题划分二级标题。
- 每个主题下挑 2–4 项作者重点讨论的研究，写"研究目的 + 关键发现"，不展开方法。
- 整合部分单独成节，呈现作者认为这些研究合起来告诉我们什么。

### 评论 / Commentary / Reply

通常结构：被评论文献的核心主张 → 作者的批评 / 补充 → 论据 → 结论。

写法重点：
- 先单独一段交代被评论的是哪篇论文（标题 + 作者 + 年份 + 核心主张），让读者有上下文。
- 然后逐条转述作者的论点。

## 整体长度参考

非实证论文"文献总结"部分总长通常在 2000–3500 中文字之间，但以完整呈现论证链为准。

---

## 注意

- 非实证论文（尤其是观点文章和理论综述）经常充满**作者自创的术语和概念框架**。这恰是写作风格章节强调的"解释 > 转述"最适用的地方：每个新概念第一次出现时给一段解释 + 例子，不要只是把名词翻成中文。
- 作者反对哪些观点、支持哪些观点要明确——观点文章的价值就在于立场，立场不能糊。
- 元分析报告主效应时，**合并效应量 + 95% CI + k（纳入研究数）+ 总样本量** 是必须给出的四个数字。
