# 0.4 复现危机与开放科学

你大概率听过 Bem (2011) 的预知能力研究、Stapel 数据造假、社会启动效应的复现失败。这些不是边角八卦，它们重塑了过去十年社会心理学的研究规范。

## 这意味着什么

当你做研究的时候，不能再像 2010 年的论文里那样写"我们做了三个研究，全部显著"——审稿人会立刻警惕。你需要：

- 足够的**统计功效**（不是 N = 30 就开始跑 ANOVA）；
- **预注册**分析路径，避免 p-hacking；
- 共享数据、材料、代码（除非伦理上不允许）；
- 报告效应量与置信区间，而不只是 p 值。

::: warning 提醒
本教程的所有统计章节都默认采用"可重复研究"的范式——你看到的代码与做法，是按照能够被同行直接复跑的标准来写的。
:::
